## 每批工作流程

一个 PDF 是章节交付单位，不是单次翻译批量。每次按小批次处理，初始默认普通文字 2—3 页、公式密集内容 1—2 页；以完整段落或推导单元为边界，根据试点调整。具体执行遵循《分批执行与质量控制.md》。先看完整相关页面，再提取文字；多栏、公式与图表以页面视觉内容为准，不能用提取结果证明准确性。

逐段执行：原文定位 → 术语和约定查阅 → 翻译/校订 → 独立重读原文复核 → 公式与图表检查 → Markdown 渲染 → 更新导读、清单和问题表。不得将同一次生成的自检描述为独立人工复核。

## Preface 阅读导航

保留作者序言与版权信息；新增部分明确标注为译者编写。包含全书目录、每章概括、每节概括及阅读建议，链接到实际译文文件。未译节仅显示待翻译，不制造不存在的链接。

本轮导读根据网页标题拟定，逐项标注待正文核验。正文完成后，每章用 2—4 句概括主题与节间关系，每节用 1—3 句说明对象、问题、主要结果或用途；必要时列出先修节和关键约定。附录具体主题必须读原文后再写。管理表保存依据页码与核验日期，Preface 保持适合阅读的简洁呈现。

## 完成标准

- 原文所有页面均有覆盖记录，段落、公式、图表、图注、脚注、文献无遗漏。
- 关键术语与符号约定经核验；公式逐项对照页面。
- 增补与原文明确区分；影响理解的疑问得到解决，其余疑问明确注记。
- 实际阅读环境中的数学、图片、表格及链接正常。
- Preface 目录、导读与译文一致，语料只收录已核验片段。

状态依次为：待翻译/旧译待校订 → 处理中 → 待复核 → 已复核待排版 → 完成。阻碍结论的问题存在时不得标为完成。专业人工复核若未进行，须明确记录。
