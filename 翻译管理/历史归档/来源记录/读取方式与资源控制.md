# 原文读取方式与资源控制

日期：2026-10-16。

## 网站核查

已保存用户指定目录页的原始 HTML，见 hirose-2026-10-16.html；页面链接见网页链接清单.tsv。该页是序言、版权说明和章节目录，正文通过 PDF 附件提供，并非 39 节 HTML 正文。网页检索工具对示例 1.1 PDF 的解析遗漏了大量日文叙述，因此不将在线解析文本作为翻译底本。在线 PDF 与本地底本的字节一致性尚未验证。

## 本项目采用的方式

1. 原文底本保持为日语原版目录中的本地 PDF。
2. 普通文字先读取全书调查/文本缓存中的本批页段；提取文本只辅助检索和初译。
3. 对照原 PDF 页面的文字、公式、图表和脚注；对含缺字、私用区字符、符号映射异常的部分重点查看原图。已查看且未变化的页面不在同批无故反复读取。
4. 每批只加载相关术语、符号约定、前文定义和少量相邻上下文，不把整份 PDF、完整词表和全书旧译反复送入工作上下文。
5. 保留已提取文本与所需页面渲染缓存；底本摘要改变后才重建相关缓存。把 PDF 转成 HTML 可以改善浏览和定位，但不能自动恢复正确的数学语义。

## 对效率的判断

结构清晰且包含可靠正文和数学编码的 HTML，通常更便于顺序读取；本网站不存在这种可直接替代 PDF 的正文。原始 HTML 还可能包含导航、样式等无关内容，应只读取所需正文。

本项目预期较有效的组合是“缓存文本辅助阅读＋PDF 页面核验”，减少重复网络读取、全书扫描和无关上下文。不能据文件类型承诺具体 token 节省比例；同样的文本换一个容器不会自然减少内容量。本轮没有测量两种方式的实际 token 消耗，不把预计效率提升表述为实测结果。
