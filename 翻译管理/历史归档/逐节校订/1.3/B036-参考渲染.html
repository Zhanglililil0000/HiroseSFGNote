[反射系数与透射系数]

为简便起见，下面考虑线偏振光。入射到表面或界面上的线偏振光可分解为 p 偏振与 s 偏振的叠加（参见注 1），故以下分别讨论 s 偏振和 p 偏振。设从介质 1 入射到介质 2 界面的光的入射电场振幅为 EisE_i^sEis​、EipE_i^pEip​，反射光和透射光的电场振幅分别为 ErsE_r^sErs​、ErpE_r^pErp​、EtsE_t^sEts​、EtpE_t^pEtp​（上标表示偏振方向）。这些振幅之间的比值（振幅反射系数、振幅透射系数）如下：

（反射系数）

r12s=Ers/Eis=(k1z−k2z)/(k1z+k2z)=(n1cos⁡θ1−n2cos⁡θ2)/(n1cos⁡θ1+n2cos⁡θ2)=−sin⁡(θ1−θ2)/sin⁡(θ1+θ2)r12p=Erp/Eip=(ε1k2z−ε2k1z)/(ε2k1z+ε1k2z)=(n1cos⁡θ2−n2cos⁡θ1)/(n2cos⁡θ1+n1cos⁡θ2)=−tan⁡(θ1−θ2)/tan⁡(θ1+θ2)(4) \begin{aligned} &r_{12}^s = E_r^s / E_i^s = (k_{1z} - k_{2z})/(k_{1z} + k_{2z}) = (n_1\cos\theta_1 - n_2\cos\theta_2)/(n_1\cos\theta_1 + n_2\cos\theta_2)\\[6pt] &= -\sin(\theta_1 - \theta_2)/\sin(\theta_1 + \theta_2)\\[6pt] & r_{12}^p = E_r^p / E_i^p = (\varepsilon_1 k_{2z} - \varepsilon_2 k_{1z})/(\varepsilon_2 k_{1z} + \varepsilon_1 k_{2z})\\[6pt] &= (n_1\cos\theta_2 - n_2\cos\theta_1)/(n_2\cos\theta_1 + n_1\cos\theta_2) = -\tan(\theta_1 - \theta_2)/\tan(\theta_1 + \theta_2) \end{aligned} \tag{4} ​r12s​=Ers​/Eis​=(k1z​−k2z​)/(k1z​+k2z​)=(n1​cosθ1​−n2​cosθ2​)/(n1​cosθ1​+n2​cosθ2​)=−sin(θ1​−θ2​)/sin(θ1​+θ2​)r12p​=Erp​/Eip​=(ε1​k2z​−ε2​k1z​)/(ε2​k1z​+ε1​k2z​)=(n1​cosθ2​−n2​cosθ1​)/(n2​cosθ1​+n1​cosθ2​)=−tan(θ1​−θ2​)/tan(θ1​+θ2​)​(4)

（p 偏振的反射系数，其符号具有一定的任意性。通常约定当 θ1+θ2<π/2\theta_1 + \theta_2 < \pi/2θ1​+θ2​<π/2 时，电场面内分量的符号与 s 偏振相同。此外，当 θ1+θ2=π/2\theta_1 + \theta_2 = \pi/2θ1​+θ2​=π/2 时 p 偏振的反射率为零，满足该条件的入射角称为布儒斯特角。注意跨越布儒斯特角时，r12pr_{12}^pr12p​ 的符号会由 −-− 翻转为 +++。）

（透射系数）

t12s=Ets/Eis=2k1z/(k1z+k2z)=2n1cos⁡θ1/(n1cos⁡θ1+n2cos⁡θ2)=2cos⁡θ1sin⁡θ2/sin⁡(θ1+θ2)t12p=Etp/Eip=2ε1k2zcos⁡θ1/(ε2k1z+ε1k2z)=2n1cos⁡θ1/(n2cos⁡θ1+n1cos⁡θ2)=2cos⁡θ1sin⁡θ2/sin⁡(θ1+θ2)cos⁡(θ1−θ2)(5) \begin{aligned} &t_{12}^s = E_t^s / E_i^s = 2k_{1z}/(k_{1z} + k_{2z}) = 2n_1\cos\theta_1/(n_1\cos\theta_1 + n_2\cos\theta_2)\\[6pt] &= 2\cos\theta_1\sin\theta_2/\sin(\theta_1 + \theta_2)\\[6pt] & t_{12}^p = E_t^p / E_i^p = 2\varepsilon_1 k_{2z}\cos\theta_1/(\varepsilon_2 k_{1z} + \varepsilon_1 k_{2z}) = 2n_1\cos\theta_1/(n_2\cos\theta_1 + n_1\cos\theta_2)\\[6pt] &= 2\cos\theta_1\sin\theta_2/\sin(\theta_1 + \theta_2)\cos(\theta_1 - \theta_2) \end{aligned} \tag{5} ​t12s​=Ets​/Eis​=2k1z​/(k1z​+k2z​)=2n1​cosθ1​/(n1​cosθ1​+n2​cosθ2​)=2cosθ1​sinθ2​/sin(θ1​+θ2​)t12p​=Etp​/Eip​=2ε1​k2z​cosθ1​/(ε2​k1z​+ε1​k2z​)=2n1​cosθ1​/(n2​cosθ1​+n1​cosθ2​)=2cosθ1​sinθ2​/sin(θ1​+θ2​)cos(θ1​−θ2​)​(5)

对于从介质 2 向介质 1 反向行进的光线，下式成立：

r21s=−r12s,r21p=−r12p \begin{aligned} &r_{21}^s = -r_{12}^s, \quad r_{21}^p = -r_{12}^p \end{aligned} ​r21s​=−r12s​,r21p​=−r12p​​
t21s=(n2cos⁡θ2/n1cos⁡θ1) t12s,t21p=(n2cos⁡θ2/n1cos⁡θ1) t12p(6) \begin{aligned} &t_{21}^s = (n_2\cos\theta_2 / n_1\cos\theta_1)\, t_{12}^s, \quad t_{21}^p = (n_2\cos\theta_2 / n_1\cos\theta_1)\, t_{12}^p \end{aligned} \tag{6} ​t21s​=(n2​cosθ2​/n1​cosθ1​)t12s​,t21p​=(n2​cosθ2​/n1​cosθ1​)t12p​​(6)

利用介电常数 ε\varepsilonε 和波矢 kkk 的表达式，在处理吸收介质或金属表面反射时尤为方便。

界面上入射侧存在的电场为入射光电场矢量与反射光电场矢量的矢量和（相比之下，透射侧的电场仅为透射光电场的矢量）。因此，入射侧电场的 xxx、yyy、zzz 分量可用入射光电场表示如下：

Ex,i=Eipcos⁡θ1,Ey,i=Eis,Ez,i=Eipsin⁡θ1, \begin{aligned} &E_{x,i} = E_i^p\cos\theta_1, \quad E_{y,i} = E_i^s, \quad E_{z,i} = E_i^p\sin\theta_1, \end{aligned} ​Ex,i​=Eip​cosθ1​,Ey,i​=Eis​,Ez,i​=Eip​sinθ1​,​

Ex,surface=[2n1cos⁡θ1cos⁡θ2/(n2cos⁡θ1+n1cos⁡θ2)] Einp=[cos⁡θ1sin⁡2θ2/sin⁡(θ1+θ2)cos⁡(θ1−θ2)] Einp,Ey,surface=[2n1cos⁡θ1/(n1cos⁡θ1+n2cos⁡θ2)] Eins=[2cos⁡θ1sin⁡θ2/sin⁡(θ1+θ2)] Eins,Ez,surface-1=[2n2sin⁡θ1cos⁡θ1/(n2cos⁡θ1+n1cos⁡θ2)] Einp={2sin⁡2θ1cos⁡θ1/[sin⁡(θ1+θ2)cos⁡(θ1−θ2)]} Einp,Ez,surface-2=[−2n1cos⁡θ1sin⁡θ2/(n2cos⁡θ1+n1cos⁡θ2)] Einp={2cos⁡θ1sin⁡2θ2/[sin⁡(θ1+θ2)cos⁡(θ1−θ2)]} Einp. \begin{aligned} &E_{x,\text{surface}} = [2n_1\cos\theta_1\cos\theta_2/(n_2\cos\theta_1 + n_1\cos\theta_2)]\, E_{\text{in}}^p\\[6pt] &= [\cos\theta_1\sin 2\theta_2/\sin(\theta_1 + \theta_2)\cos(\theta_1 - \theta_2)]\, E_{\text{in}}^p,\\[6pt] & E_{y,\text{surface}} = [2n_1\cos\theta_1/(n_1\cos\theta_1 + n_2\cos\theta_2)]\, E_{\text{in}}^s\\[6pt] &= [2\cos\theta_1\sin\theta_2/\sin(\theta_1 + \theta_2)]\, E_{\text{in}}^s,\\[6pt] & E_{z,\text{surface-1}} = [2n_2\sin\theta_1\cos\theta_1/(n_2\cos\theta_1 + n_1\cos\theta_2)]\, E_{\text{in}}^p\\[6pt] &= \{2\sin^2\theta_1\cos\theta_1/[\sin(\theta_1 + \theta_2)\cos(\theta_1 - \theta_2)]\}\, E_{\text{in}}^p,\\[6pt] & E_{z,\text{surface-2}} = [-2n_1\cos\theta_1\sin\theta_2/(n_2\cos\theta_1 + n_1\cos\theta_2)]\, E_{\text{in}}^p\\[6pt] &= \{2\cos\theta_1\sin^2\theta_2/[\sin(\theta_1 + \theta_2)\cos(\theta_1 - \theta_2)]\}\, E_{\text{in}}^p. \end{aligned} ​Ex,surface​=[2n1​cosθ1​cosθ2​/(n2​cosθ1​+n1​cosθ2​)]Einp​=[cosθ1​sin2θ2​/sin(θ1​+θ2​)cos(θ1​−θ2​)]Einp​,Ey,surface​=[2n1​cosθ1​/(n1​cosθ1​+n2​cosθ2​)]Eins​=[2cosθ1​sinθ2​/sin(θ1​+θ2​)]Eins​,Ez,surface-1​=[2n2​sinθ1​cosθ1​/(n2​cosθ1​+n1​cosθ2​)]Einp​={2sin2θ1​cosθ1​/[sin(θ1​+θ2​)cos(θ1​−θ2​)]}Einp​,Ez,surface-2​=[−2n1​cosθ1​sinθ2​/(n2​cosθ1​+n1​cosθ2​)]Einp​={2cosθ1​sin2θ2​/[sin(θ1​+θ2​)cos(θ1​−θ2​)]}Einp​.​

对于 p 偏振，以布儒斯特角为界，入射光与反射光的电场矢量中，面内分量（xxx 分量）的方向由 −-− 变为 +++，而法线分量（zzz 分量）的方向则由 +++ 变为 −-−。因此需要注意，不能简单地将 1+r12p1 + r_{12}^p1+r12p​ 当作 p 偏振的表面电场。

极化矢量及极化率张量的表达式是按坐标轴分量给出的。为此，取界面为 xyxyxy 面，以从入射侧指向透射侧的法线为 zzz 轴，以 s 偏振电场的方向为 yyy 轴，并以光的行进方向为正定义 xxx 轴。此时，各坐标轴分量的反射系数和透射系数如下：

r12x=r12p,r12y=r12s,r12z=−r12p,(7a) \begin{aligned} &r_{12}^x = r_{12}^p, \quad r_{12}^y = r_{12}^s, \quad r_{12}^z = -r_{12}^p, \end{aligned} \tag{7a} ​r12x​=r12p​,r12y​=r12s​,r12z​=−r12p​,​(7a)
t12x=(cos⁡θ2/cos⁡θ1) t12p,t12y=t12s,t12z=(sin⁡θ2/sin⁡θ1) t12p.(7b) \begin{aligned} &t_{12}^x = (\cos\theta_2/\cos\theta_1)\,t_{12}^p, \quad t_{12}^y = t_{12}^s, \quad t_{12}^z = (\sin\theta_2/\sin\theta_1)\,t_{12}^p. \end{aligned} \tag{7b} ​t12x​=(cosθ2​/cosθ1​)t12p​,t12y​=t12s​,t12z​=(sinθ2​/sinθ1​)t12p​.​(7b)
