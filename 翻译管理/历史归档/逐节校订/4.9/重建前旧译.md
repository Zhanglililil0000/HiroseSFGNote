## 1. 金刚石表面C-H伸缩振动的SFG光谱

金刚石C(100)表面根据制备条件的不同，会呈现出不同的SFG光谱。表面碳原子的键合状态决定了与C(100)表面有关的振动模式。在as-cut表面上，表面碳原子具有两个悬挂键（dangling bond），其中一个键被氢原子终结形成单氢化物构型（monohydride，参见图(a)），另一个键则悬空。此外，as-cut表面经处理后可形成两个悬挂键均被氢终结的二氢化物构型（dihydride，参见图(b)）。图中以点线表示CH键，外侧左侧为HCCH单元，右侧为CH2单元。这是各个单元内伸缩振动的示意图。本章将对HCCH和CH2单元的SFG张量进行详细讨论。

金刚石的晶格常数为3.567 A，C-C键长为1.545 A。此外，表面碳原子在as-cut表面上的间距为2.51 A。作为参考，该值（2.51 x 5.1 A）即为单胞尺寸（R. E. Stallcup et al., Appl. Phys. Lett. 66, 2331(1995)）。C-C键的四面体角约为109.5度，sp3杂化轨道角约为109.5度。C-H键长约为1.1~1.2 A。

考虑CH2（图(b)）的构型，两个相邻CH2的H原子间距约为0.7 A左右。另一方面，对于HCCH单元（图(a)），相邻单元的H原子间距约为2 A左右（CH键相对于表面法线方向倾斜约30度，相对于另一CH键方向倾斜约55度，形成锯齿形排列）。虽然分子取向因表面处理而不同，但氢原子的范德华半径为1.20 A。若分子间距约2.4 A以上，则相邻分子间的相互作用可忽略不计。在情况(b)中，由于Y方向上的缩进，相互作用可能不可忽略。而在情况(a)中，HCCH单元的H原子间距较大，相互作用可能并不重要。因此，以下将CH伸缩振动的讨论限定在孤立CH基团上，忽略横向相互作用。如果有横向相互作用，则表面上的H原子与外侧的H原子或内侧的H原子之间的耦合必须加以考虑。

## 2. 分子坐标 (abc) 系中的张量要素

CH2的对称性为C2v，HCCH单元因两个CC键不等价而失去对称性。HCCH单元有两种类型：对称型（C2v对称性）和反对称型（C2对称性）。

在C2v对称性下，H原子的两个CC键等价，因此对应的"对称"和"反对称"振动模式之间无耦合，从而两个伸缩振动的SFG张量元可以用本节前面给出的张量公式表示。在C2对称性下，"对称"与"反对称"均包含两个CH伸缩振动的贡献，HCCH张量元中会有交叉项出现。

CH2单元：由3原子构成的体系。2个H原子的位相由C2v对称性决定。

## 2. 坐标系与坐标定义

**1. 分子固定坐标系：(abc) 系**

- CH2：C2对称轴沿c轴，分子平面为ac面。
- HCCH：C2对称轴沿c轴，对称型(C2v)中分子平面为ac面（包含CC轴），反对称型(C2)中两个CCH面的角平分面为ac面（即CCC角的平分面）。

**2a. 实验室坐标系：(xyz) 系**

**2b. 空间固定坐标系：(XYZ) 系**

**3. 分子取向：欧拉角 (c, q, f)**

将分子从 (abc) 系变换到 (xyz) 系所需要的旋转操作由三个欧拉角 (c, q, f) 决定。欧拉角 (c, q, f) 的含义如下：

- **(1) 方位角 f**：绕ac面法线（对于CH2和HCCH，分子包含2个CH伸缩振动）进行旋转。c轴绕ac面的垂线旋转出ac面。该旋转角称为方位角f。当ac面与z轴平行、a轴与x轴方向一致时为起始位置（f = 0 or p），当ac面与z轴平行且a轴向xy面投影与ab轴方向一致时（f = p/2 or 3p/2）。分子绕表面法线的方位角f可以在0 ~ 2p之间任意取值。

- **(2) 倾斜角（tilt角）q_tilt**：倾斜分子使c轴从表面法线方向（-z）倾斜。注意z轴指向外侧，c轴指向内侧，ab面在xy面内旋转。c轴绕表面法线方向旋转的角即为欧拉角 q = p - q_tilt。

- **(3) 面内旋转角 c_in-plane（记为 cip）**：绕z轴旋转后，c轴在xy面内投影与x轴的夹角。由于z轴指向外侧，x轴指向特定的面内方向。绕z轴的旋转角即为欧拉角 c = p/2 + cip。分子绕表面法线的面内旋转角cip可以在0 ~ 2p之间任意取值。

## 3. 分子 (abc) 系中张量要素的推导

利用Euler旋转矩阵将各个张量元导入。C2v分子（CH2和对称HCCH）有：$b_{aac}, b_{bbc}, b_{ccc}; b_{caa} = b_{aca}, b_{cbb} = b_{bcb}$。C2分子（反对称HCCH）有：$b_{aac}, b_{bbc}, b_{ccc}, b_{abc} = b_{bac}, b_{caa} = b_{aca}, b_{bca} = b_{cba}, b_{cbb} = b_{bcb}, b_{cab} = b_{acb}$。

对于CH的张量元表达式，利用CH2和HCCH的旋转角公式重新表述。CH2用欧拉角文件 Eu-5，有以下性质：

(1) 两个CH振动以旋转角 c（相差 p）成对出现，$\sin c, \sin 3c, \cos c, \cos 3c$ 都会出现" + / - "项。当 c = 0 或 p 时，$\sin 2c = 0, \cos 2c = +1$，$\sin 2c$与$(1 - \cos 2c)$成对出现。
(2) 角 f 同样，当其为0时，$\sin f = \sin 2f = \sin 3f = 0, \cos f = \cos 2f = \cos 3f = +1$，$\sin f, \sin 2f, \sin 3f, (1 - \cos 2f)$ 成对出现。

利用这些性质，并将CH振动张量改写为两个CH振动的组合（CH2用Eu-5，对称HCCH用Eu-6，反对称HCCH用Eu-8/Eu-10）：

### CH2的分子张量（HCH角 = 四面体角）

$a$ 为HCH角。设四面体角：$\cos a = -1/3, \sin a = 2\sqrt{2}/3$，则 $\cos(a/2) = \sqrt{1/3}$。

$$
\begin{aligned}
b_{aac} &= 2\{b_{xxz}\cos^3(a/2) + b_{zzz}[\cos(a/2) - \cos^3(a/2)]\} \tag{3-1a} \\
b_{bbc} &= 2b_{hhz}\cos(a/2) \tag{3-1b} \\
b_{ccc} &= 2\{b_{xxz}[\cos(a/2) - \cos^3(a/2)] + b_{zzz}\cos^3(a/2)\} \tag{3-1c} \\
b_{caa} = b_{aca} &= -2(b_{xxz} - b_{zzz})[\cos(a/2) - \cos^3(a/2)] \tag{3-2} \\
b_{cbb} = b_{bcb} &= 0 \tag{3-3}
\end{aligned}
$$

（CH伸缩的 $b$ 张量因此由上述 $b$ 张量叠加而成）

代入四面体角数值：$\cos a = -1/3, \sin a = 2\sqrt{2}/3$，$\cos(a/2) = \sqrt{1/3}$，得到：

$$
\begin{aligned}
b_{aac} &= (\pm 2\sqrt{3}/9)(b_{xxz} + 2b_{zzz}) \tag{3-4a} \\
b_{bbc} &= (\pm 2\sqrt{3}/9)(3b_{hhz}) \tag{3-4b} \\
b_{ccc} &= (\pm 2\sqrt{3}/9)(2b_{xxz} + b_{zzz}) \tag{3-4c} \\
b_{caa} = b_{aca} &= -(\pm 4\sqrt{3}/9)(b_{xxz} - b_{zzz}) \tag{3-5}
\end{aligned}
$$

CH振动张量由此得出，其中 $b_{aac} \sim b_{ccc}$ 的大小关系明确。

### 对称HCCH的分子张量

利用欧拉角文件 Eu-6 替换 Eu-5 中的 $(a/2)$ 为 $a - p/2$ 即可（其中 $a$ 为HCC角）。代入HCC四面体角 $\cos a = -1/3, \sin a = 2\sqrt{2}/3$：

$$
\begin{aligned}

### 反对称 HCCH (C2 对称) 的有贡献张量

反对称HCCH（C2对称）的情形需要额外加入 $b_{abc}, b_{bca}, b_{cab}, b_{cbb}$ 等交叉项。由于公式极其冗长，完整表达式包含在附件"分子配向.doc"中。此处仅给出摘要：反对称HCCH的张量等于上述C2v张量加上含有 $b_{abc}, b_{bca}, b_{cab}, b_{cbb}$ 等 $b_{c\beta\gamma}$ 项的修正。具体来说：

- 所有有贡献张量元的总表达式 = C2v表达式 + 修正项
- 修正项包含 $b_{abc}, b_{bca}, b_{cab}, b_{cbb}$ 及其与 $c, q, f$ 的三角函数的乘积组合

### 反对称 HCCH (C2 对称) 的无贡献张量

无贡献张量元也被修正为包含全部 $b_{c\beta\gamma}$ 成分的表达式：

- $c_{XXX}$ 包含 $(b_{caa} + b_{cbb})$ 和 $(b_{caa} - b_{cbb})$ 以及 $(b_{bca} + b_{cab})$ 和 $(b_{bca} - b_{cab})$ 的各项
- 所有其他无贡献张量元类似地被扩展

详细的完整推导和所有公式请参阅"分子配向.doc"文件，其中包含利用欧拉角进行的各CH伸缩振动SFG张量以及CH2和HCCH分子取向与SFG张量的完整推导。
