## 引言

本文记述从甲基的和频光谱中提取甲基取向信息时所需的事项。第4a部分中给出的全对称伸缩振动表达式，也可以直接用于CH基团。

## 1. 欧拉角

要指定共用原点的两个直角坐标系——$(xyz)$系与$(abc)$系——之间的关系，可以用依次旋转一个坐标系、使其与另一个坐标系重合时所需的三个角来定义。这三个角称为欧拉角，定义如下。（这里考虑把$(abc)$轴重合到$(xyz)$轴上的操作；沿旋转轴从负侧朝正方向观察时，将顺时针旋转取为正旋转。）

(1) 将$ab$面与$xy$面的交线（通过原点）命名为$N$轴。选取$N$轴的正方向，使绕该轴旋转、将$c$轴重合到$z$轴上时的旋转角不超过$180^\circ$。

(2) 将绕$c$轴旋转、使$b$轴重合到$N$轴上所需的旋转角记为$\phi$，其中$0\leq\phi<2\pi$。

$N$轴同时位于$xy$面和$ab$面内，而$a'$轴、$c$轴、$z$轴均垂直于$N$轴。因此，$a'$、$c$、$z$三轴共面，且$a'c$面垂直于$xy$面。此外，这一旋转操作使$a$轴与$z$轴在$ab$面上的投影重合。（不过，方向上仍有$180^\circ$的任意性……）

(3) 将绕$N$轴旋转、使$c$轴重合到$z$轴上的角记为$\theta$，其中$0\leq\theta<\pi$。

通过这一操作，$ab$面与$xy$面重合。

(4) 将绕$z$轴旋转、使$N$轴重合到$y$轴上的角记为$\chi$，其中$0\leq\chi<2\pi$。

通过这一操作，$c$轴在$xy$面上的投影重合到$x$轴上，$a''z$面也与$zx$面重合。（同样，方向上仍有$180^\circ$的任意性……）

对$(abc)$系先进行操作(2)，再进行操作(3)，最后进行操作(4)，便使$(abc)$系与$(xyz)$系重合。

另有一种定义：将(2)中的“使$b$轴重合到$N$轴上”和(4)中的“使$N$轴重合到$y$轴上”，分别换为“使$a$轴重合到$N$轴上”和“使$N$轴重合到$x$轴上”。两种定义给出的坐标分量变换系数不同，必须注意。此外，本文经常使用负旋转角，这是因为旋转具有$2\pi$周期，旋转$2\pi-\alpha$与旋转$-\alpha$相同。（对照上述定义，这一讨论对于$\theta$并不成立。由欧拉角$(\chi,-\theta,\phi)$进行的旋转，与由$(\pi+\chi,\theta,\pi+\phi)$进行的旋转一致。）

矢量及张量的坐标分量之间的变换系数，已在另一个文件《变换矩阵(xyz)》中列成表格（也刊载于 *Appl. Spectrosc.*）。对于和频张量的坐标分量，使用表中给出的变换系数$U_{ijk:abc}$，按下式将$(abc)$系中表示的分量变换为$(xyz)$系中的分量：

$$
\chi_{ijk}=\sum U_{ijk:abc}\chi_{abc},\qquad(i,j,k=a,b,c).
$$

> **译者注（原文疑点Q138，PDF p2）：** 原式求和号未标范围，式后写作$(i,j,k=a,b,c)$；前文则说要得到$(xyz)$系分量。候选为输出指标应取$x,y,z$，并对分子指标求和，尚未采用。$U$是变换系数，不能像旧译那样称为分子超极化率。这里的$\chi$按原式保留，不据此改写本节后文的分子$\beta$。

> **译者注（本节约定）：** $N$是两坐标面的交线轴，不是欧拉角。三个角为$\phi,\theta,\chi$，旋转顺序和角度范围依上述原文保留；不沿用第4.1节的角度符号。第2部分定义表面$z$轴指向基板内部，而倾斜角从外向法线计量，须在后续变换中分别处理。

## 2. CH基团的坐标变换

本书所采用的坐标系中，一般而言，$z$ 轴取为表面法线方向，$x$ 轴与 $y$ 轴取在表面面内。在SFG实验的入射面取为 $x$ 方向的通常条件下，LB膜等的沉积方向通常取为 $x$ 方向。根据 Born & Wolf、Bloembergen 以及 Shen 等人的文献，本章也取 $z$ 轴为表面法线方向。

分子相对于 $z$ 轴的取向由分子的倾斜角（tilt angle）来描述。下文将 tilt 角记为 $q_{\text{tilt}}$。

在上述定义的坐标系中，C原子的三个等价H原子围绕 $C_3$ 轴作对称排列。CH基团的振动主要产生沿CH键 $a$ 方向的极化率变化分量——$b_{aac}$，即 CH(1) 的各种极化率分量中 $ac$ 方向的极化率张量分量。

下文将基于以下参数，对分子的取向进行规定。

(1) 方位角 $f$：分子（分子轴）的面内取向。$x$ 轴沿入射面方向取为固定方向。由于 $ac$（即分子轴方向，对应 CH(1) 基团）相对于 $x$ 轴的取向发生变化，入射面与分子轴之间的夹角即为此方位角。方位旋转角 $f$ 的含义如下：
  (a) $x$ 轴沿入射面固定；
  (b) $a$ 轴绕 $c$ 轴旋转，使其在 $ac$ 面内相对于 $xy$ 面内 $x$ 轴的投影具有方位角（$a$ 轴在 $xy$ 面内的方向角即为 $f$）；
  (c) 线 $a$ 在 $xy$ 平面上的投影与 $x$ 轴之间的夹角即为方位角（$a$ 轴的 $x$ 分量与 $x$ 轴的差异即为 $f$）；
  (d) 当 XCH(1) 的 $a$ 轴投影与 ACH(1) 的 $a$ 轴投影在一条直线上时，$f = 0$；ACH(1) 的 $a$ 轴投影在相反方向时，$f = \pi$；
  (e) 当三根CH基团等价时，各基团的方位角分别取 $f$、$f + 2\pi/3$、$f + 4\pi/3$（即每根相差 $120^\circ$）；
  (f) 当两根CH基团等价时，各基团的方位角分别取 $f + 2\pi/3$ 和 $f - 2\pi/3$（即每根相对于 $f$ 对称分布）。严格来说，此时方位角仍可取 $f$ 的任意值；
  (g) 对于自由旋转的情况，$f$ 在 $0$ 到 $2\pi$ 之间均匀分布，即取连续分布。

(2) 倾斜角 $q_{\text{tilt}}$（tilt角）：分子的 $c$ 轴（即 $C_3$ 轴）与表面法线方向之间的夹角。$N$ 的旋转使 $c$ 轴倾斜从而偏离表面法线方向。本书中 tilt 角以 $q_{\text{tilt}}$ 表示，欧拉角中的 $q$ 等于 $\pi - q_{\text{tilt}}$。对于三根CH基团等价的情况，通常 $q_{\text{tilt}} < \pi/2$。

(3) 面内旋转角 $c_{\text{ip}}$（in-plane，记为 $c_{\text{ip}}$）：在 $z$ 轴的旋转中，$xy$ 平面内 $a$ 轴的投影线与 $x$ 轴之间的夹角即为 $c_{\text{ip}}$。$x$ 轴沿入射面方向固定，因此 $a$ 轴在入射面内的投影方向可取 $+a$ 方向或 $-a$ 方向。当 $a$ 轴在 $C_3$ 对称操作下变换为新的 $x$ 方向时（如 $C_3$ 操作使 $a$ 旋转 $120^\circ$），$c_{\text{ip}}$ 相应地可取 $+a$ 或 $-a$ 的值。对于自由旋转的情况，由于 $C_3$ 轴的分布，$c_{\text{ip}}$ 在 $0$ 到 $2\pi$ 范围内均匀分布。

本书 $(x, y, z)$ 系的 $z$ 取为表面法线方向，因此上述欧拉角中 $c = \pi + c_{\text{ip}}$。当 $C_3$ 旋转将分子从一侧旋转到另一侧时，欧拉角的取值可能相差 $2\pi$，但最终结果与欧拉角的特定选取无关。确认上述所取的 $f$、$q$、$c$ 之间的对应关系后，汇总如下：

$$f = f, \quad q = \pi - q_{\text{tilt}}, \quad c = \pi + c_{\text{ip}}$$

## 3. 分子极化率的坐标变换（$abc$ 系）

如前所述，关于 $(xyz)$ 系的张量表示参见 Appl. Spectrosc. 文献，此处给出推导结果。为了将CH基团的SFG光谱强度以张量分量的形式表达，需将分子极化率张量从分子坐标系变换到实验室坐标系。

CH基团的分子坐标系取为 $(xhz)$ 系：$z$ 轴沿C原子到H原子的方向（即 $C_3$ 对称轴方向），$xz$ 面定义为包含 $ab$ 面内 $x$ 方向（即三根等价CH基团中某一根的CH键方向 $a$）与 $z$ 轴的平面。$\theta$ 为 $ab$ 面内 $a$ 轴与 $z$ 轴的夹角。当 $\theta < \pi$ 时，$a$ 轴绕 $z$ 轴旋转，CH基团随之倾斜。

对于三根CH基团，在 $(xhz)$ 系中取以下欧拉角 $(c, q, f)$：

CH(1)：$(\pi, \pi - t, 0)$
CH(2)：$(5\pi/3, \pi - t, 0)$
CH(3)：$(\pi/3, \pi - t, 0)$

其中，$t$ 为 HCX 的键角，四面体键角下满足：
$$\cos t = -1/3,\quad \sin t = \sqrt{8}/3$$

由此可计算各三角函数值（这些值在后续推导中是必需的）：

$$\sin f = 0,\; \sin 2f = 0,\; \sin 3f = 0,\; \cos f = 1,\; \cos 2f = 1,\; \cos 3f = 1$$

$$\sin q = \sqrt{8}/3,\; \sin 2q = -\sqrt{32}/9,\; \sin 3q = -10\sqrt{2}/27,\; \cos q = 1/3,\; \cos 2q = -7/9,\; \cos 3q = -23/27$$

CH(1)：
$$\sin c = 0,\; \sin 2c = 0,\; \sin 3c = 0,\; \cos c = -1,\; \cos 2c = 1,\; \cos 3c = -1$$

CH(2)：
$$\sin c = -\sqrt{3}/2,\; \sin 2c = -\sqrt{3}/2,\; \sin 3c = 0,\; \cos c = 1/2,\; \cos 2c = -1/2,\; \cos 3c = -1$$

CH(3)：
$$\sin c = \sqrt{3}/2,\; \sin 2c = \sqrt{3}/2,\; \sin 3c = 0,\; \cos c = 1/2,\; \cos 2c = -1/2,\; \cos 3c = -1$$

对于CH基团，由于CH键沿 $z$ 轴方向的极化率分量远大于其他方向，SFG张量分量中 $b_{xxz}$、$b_{hhz}$、$b_{zzz}$ 为主要分量。在目前的对称性下，有 $b_{xxz} = b_{hhz}$。

利用 Appl. Spectrosc. 文献中给出的 $(xyz)$ 系与 $(abc)$ 系之间的变换关系，以及 $(xhz)$ 系与 $(abc)$ 系之间的变换关系，可推得三根CH基团的 $b_{xxz}$、$b_{hhz}$、$b_{zzz}$ 与分子极化率张量元 $b_{aaa}$、$b_{aab}$ 之间的关系表达式。将三根CH基团的分量分别列出，可得以下结果。

将三根CH基团的分量进行矢量合成后，$b_{xxz}$、$b_{hhz}$、$b_{zzz}$ 与CH基团的分子极化率张量之间的关系如下：

$$\begin{aligned}
b_{aaa} &= -\frac{\sqrt{2}}{18}(b_{xxz} - 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{abb} &= -\frac{\sqrt{2}}{18}(b_{xxz} - 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{bab} &= -\frac{\sqrt{2}}{18}(b_{xxz} - 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{bba} &= -\frac{\sqrt{2}}{18}(b_{xxz} - 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{caa} &= -\frac{4}{9}(b_{xxz} - b_{zzz}) \\[4pt]
b_{cbb} &= -\frac{4}{9}(b_{xxz} - b_{zzz}) \\[4pt]
b_{aca} &= -\frac{4}{9}(b_{xxz} - b_{zzz}) \\[4pt]
b_{bcb} &= -\frac{4}{9}(b_{xxz} - b_{zzz}) \\[4pt]
b_{aac} &= \frac{1}{18}(b_{xxz} + 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{bbc} &= \frac{1}{18}(b_{xxz} + 9b_{hhz} + 8b_{zzz}) \\[4pt]
b_{ccc} &= \frac{1}{9}(8b_{xxz} + b_{zzz})
\end{aligned}$$

在 $b_{zzz} \gg b_{xxz},\, b_{hhz}$（其中 $b_{xxz} \sim b_{hhz} \sim 0.1\,b_{zzz}$）的条件下，有：

$$b_{aac} = b_{bbc} \approx \frac{4}{9} b_{zzz}, \quad b_{ccc} \approx \frac{1}{9} b_{zzz}$$

上述即为全对称（$A_1$）模式的分量。此外，

$$b_{caa} = b_{aca} = b_{cbb} = b_{bcb} \approx -\frac{4}{9} b_{zzz}$$

$$b_{aaa} = -b_{bba} = -b_{abb} = -b_{bab} \approx -\frac{\sqrt{32}}{9} b_{zzz}$$

上述即为简并模式的分量。

由此可知，对于CH基团，$b_{zzz} \gg b_{xxz},\, b_{hhz}$，且 $b_{aac} \approx 4b_{ccc}$。这意味着在分子坐标系中，$c$ 方向的张量分量与 $a$、$b$ 方向的张量分量相比，其大小关系与实验室坐标下的情况至少存在定量差异。

在CH$_3$基团的振动中，全对称模式包含 $c$ 方向的极化率变化分量，而简并模式包含 $a$、$b$ 方向的极化率变化分量。张量分量的这种差异导致了SFG、VIS以及IR光谱中各谱带强度的不同。因此，根据偏光方向的不同，SFG光谱强度会表现出不同的偏振依赖性。全对称模式的SFG光谱强度来源于 $b_{aac} = b_{bbc}$ 和 $b_{ccc}$，而简并模式的SFG光谱强度来源于 $b_{aaa} = -b_{abb} = -b_{bab} = -b_{bba}$ 以及 $b_{caa} = b_{cbb} = b_{aca} = b_{bcb}$（在 $b_{xxz} = b_{hhz}$ 的条件下，这些分量之间的关系与上述一致）。

## 4. 实验室极化率的坐标变换（$xyz$ 系）

实验室坐标系 $(xyz)$ 中的张量分量通过前述欧拉角 $(c, q, f)$ 进行表达。根据 Appl. Spectrosc. 文献中的结果，能较为容易地推导出各分量的表达式。关于 tilt 角 $q$ 的三角函数 $\sin q$、$\sin 2q$、$\sin 3q$ 等，可利用倍角公式以 $\sin q$、$\cos q$ 表示：

$$\begin{aligned}
\sin 2q &= 2\sin q\cos q \\[2pt]
\cos 2q &= \cos^2 q - \sin^2 q = 2\cos^2 q - 1 = 1 - 2\sin^2 q \\[2pt]
\sin 3q &= 3\sin q - 4\sin^3 q \\[2pt]
\sin q + \sin 3q &= 4(\sin q - \sin^3 q) \\[2pt]
\cos 3q &= 4\cos^3 q - 3\cos q \\[2pt]
\cos q - \cos 3q &= 4(\cos q - \cos^3 q)
\end{aligned}$$

关于分子内CH基团的张量分量，简并模式的情况较为复杂。在 $C_{3v}$ 对称性的情形中，两根简并模式的偏振方向——$a$ 方向的分量与 $b$ 方向的分量——具有不同的张量表达式。此时，全对称模式的SFG分量由 $b_{aac}$、$b_{bbc}$、$b_{ccc}$ 三个分量表达，其中 $b_{aac}$ 与 $b_{bbc}$ 为完全相同的分量。简并模式的SFG分量则由 $b_{aaa}$、$b_{bba}$、$b_{caa}$、$b_{aca}$ 组成一套，以及 $b_{abb}$、$b_{bab}$、$b_{cbb}$、$b_{bcb}$ 组成另一套，两套之间的分量对应相等。

以下各式中，$ac$ 面与 $xz$ 面之间的夹角（方位角）为 $f$，绕表面法线的倾斜角为 $q_{\text{tilt}}$，$a$ 轴入射面内投影与 $x$ 轴的夹角（面内旋转角）为 $c_{\text{ip}}$，使用的欧拉角参数为：

$$f = f, \quad q = \pi - q_{\text{tilt}}, \quad c = \pi + c_{\text{ip}}$$

下面给出各情况下的张量分量表达式。

### 4a. 一般公式

首先给出无任何平均时的最基本表达式。关于分子取向，暂不作取向分布平均，仅列出张量分量的代数形式。此处主要给出 CH 基团 SFG 强度评价中实际用到的分量。

**全对称模式** （$b_{zzz} \gg b_{xxz},\, b_{hhz}$ 的条件下：$b_{aac} \approx \frac{4}{9}b_{zzz}$，$b_{ccc} \approx \frac{1}{9}b_{zzz}$）

$(ppp)$：
$$\begin{aligned}
c_{xxx} &= \frac{1}{4}(b_{aac} - b_{ccc})\sin 3q(3\cos c + \cos 3c) - b_{aac}\sin q \cos c \\[4pt]
c_{xzz} &= (b_{aac} - b_{ccc})(\sin q - \sin 3q)\cos c \\[4pt]
c_{zxz} &= (b_{aac} - b_{ccc})(\sin q - \sin 3q)\cos c \\[4pt]
c_{zzx} &= (b_{aac} - b_{ccc})(\sin q - \sin 3q)\cos c - b_{aac}\sin q \cos c \\[4pt]
c_{xzx} &= -\frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)(1 + \cos 2c) \\[4pt]
c_{zxx} &= -\frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)(1 + \cos 2c) \\[4pt]
c_{xxz} &= -\frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)(1 + \cos 2c) + b_{aac}\cos q \\[4pt]
c_{zzz} &= -(b_{aac} - b_{ccc})\cos 3q + b_{aac}\cos q
\end{aligned}$$

$(spp)$：
$$\begin{aligned}
c_{yxx} &= -\frac{1}{4}(b_{aac} - b_{ccc})\sin 3q(\sin c + \sin 3c) \\[4pt]
c_{yzz} &= -(b_{aac} - b_{ccc})(\sin q - \sin 3q)\sin c \\[4pt]
c_{yzx} &= \frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)\sin 2c \\[4pt]
c_{yxz} &= \frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)\sin 2c
\end{aligned}$$

$(ssp)$：
$$\begin{aligned}
c_{yyx} &= \frac{1}{4}(b_{aac} - b_{ccc})\sin 3q(\cos c - \cos 3c) - b_{aac}\sin q \cos c \\[4pt]
c_{yyz} &= -\frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)(1 - \cos 2c) + b_{aac}\cos q
\end{aligned}$$

$(psp)$：
$$\begin{aligned}
c_{xyx} &= -\frac{1}{4}(b_{aac} - b_{ccc})\sin 3q(\sin c + \sin 3c) \\[4pt]
c_{zyz} &= -(b_{aac} - b_{ccc})(\sin q - \sin 3q)\sin c \\[4pt]
c_{xyz} &= \frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)\sin 2c \\[4pt]
c_{zyx} &= \frac{1}{2}(b_{aac} - b_{ccc})(\cos q - \cos 3q)\sin 2c
\end{aligned}$$

## 5. 各种分子对称性下的SFG张量分量

以下给出在各种分子对称性条件下SFG张量分量的具体形式。所使用的面内旋转角 $c$（即 $ac$ 面与 $xz$ 面之间的夹角（方位角）$f$、绕表面法线的倾斜角 $q_{\text{tilt}}$、$a$ 轴入射面内投影与 $x$ 轴的夹角（面内旋转角）$c_{\text{ip}}$ 中的 $c_{\text{ip}}$）在以下各式中明确写出。张量分量表达式中使用的欧拉角参数统一为：

$$f = f, \quad q = \pi - q_{\text{tilt}}, \quad c = \pi + c_{\text{ip}}$$

对于各对称性系统，下面分别给出对应不同面内旋转角 $c$ 分布的张量分量。一般来说，对于不具备面内各向异性的体系（即面内无序的情形），需要通过对面内旋转角进行平均来获得有效分量。但若体系存在面内各向异性（如 LB 膜存在沉积方向，导致面内取向存在一定的择优方向），则 $c$ 的取值必须根据实际的面内取向分布来确定。此时，面内取向分布可通过面内取向角 $c$ 的分布函数（director）来定量描述——这与液晶物理中的 director 概念类似——并从实验数据中提取面内取向的分布参数。

在 $C_s$ 对称性体系中（见 5d 节），由于对称性较低，原则上所有偏振组合均可观测到 SFG 信号，包括全对称模式和简并模式。而对于具有更高对称性的体系，某些偏振组合下的信号会消失。

在此情况下，由于 $\sum\sin c = \sum\cos c = \sum\sin 2c = \sum\cos 2c = \sum\sin 3c = \sum\cos 3c = 0$，结果与 5a 节（面内无序的情况）完全相同。

### 5d. $C_s$ 对称性系统的SFG张量分量

在 $C_s$ 对称性条件下，表面由镜像对称性所支配。LB膜等体系由于沉积方向的存在，分子在面内具有两个择优取向，即沿 $+b$ 方向与 $-b$ 方向。这两个取向的面内旋转角 $a$ 相等，面内旋转角 $c_{\text{ip}}$ 取值分别为 $a + b$ 与 $a - b$，即两个方向对称分布。

使用的欧拉角参数为：$f = f$，$q = \pi - q_{\text{tilt}}$，$c = \pi + c_{\text{ip}}$。

利用以下关系：
$$\sin c = -\sin c_{\text{ip}}, \quad \cos c = -\cos c_{\text{ip}}$$
$$\sin 2c = \sin 2c_{\text{ip}}, \quad \cos 2c = \cos 2c_{\text{ip}}$$
$$\sin 3c = -\sin 3c_{\text{ip}}, \quad \cos 3c = -\cos 3c_{\text{ip}}$$

将两个取向的张量分量求和，利用三角函数求和公式（两个相对 $c$ 对称的位置求和）可得：

$$1 = 2, \quad \sum\sin c_{\text{ip}} = 2\sin a \cos b, \quad \sum\cos c_{\text{ip}} = 2\cos a \cos b,$$
$$\sum\sin 2c_{\text{ip}} = 2\sin 2a \cos 2b, \quad \sum\cos 2c_{\text{ip}} = 2\cos 2a \cos 2b,$$
$$\sum\sin 3c_{\text{ip}} = 2\sin 3a \cos 3b, \quad \sum\cos 3c_{\text{ip}} = 2\cos 3a \cos 3b$$

当 $b = 0$（即 $C_{2v}$ 极限情况）时，上述表达式可进一步简化。此时，全对称模式的 $(spp)$、$(psp)$、$(pps)$、$(sss)$ 偏振组合无信号，简并模式则在 $(spp)$、$(psp)$、$(pps)$、$(sss)$ 偏振组合中出现信号。

## 6. 局域场修正与SFG强度

SFG的分极强度 $P(\omega_{\text{SF}})$ 由入射电场（入射红外电场 $E^{(i)}(\omega_{\text{IR}})$、入射可见电场 $E^{(i)}(\omega_{\text{vis}})$ 以及反射红外电场 $E^{(r)}(\omega_{\text{IR}})$、反射可见电场 $E^{(r)}(\omega_{\text{vis}})$ 的矢量合成）与其对应的张量分量的乘积决定。

$$P_i(\omega_{\text{SF}}) = \sum_{j,k} \chi^{\text{SF}}_{ijk}\, E_j(\omega_{\text{vis}})\, E_k(\omega_{\text{IR}}) \tag{6.1}$$

其中，下标 $i$、$j$、$k$ 分别对应 SFG 光、可见光和红外光的偏振方向（$i, j, k = x, y, z$）。

对于各入射光，以入射角 $q_I$ 将入射电场 $E^{(i)}$ 分解为 $p$ 偏振分量与 $s$ 偏振分量（$E^{(i)} = E^{(i)}_p + E^{(i)}_s$），其与实验坐标 $x$、$y$、$z$ 分量的关系为：

$$E_x^{(i)} = E_p^{(i)}\cos q_i, \quad E_y^{(i)} = E_s^{(i)}, \quad E_z^{(i)} = -E_p^{(i)}\sin q_i \tag{6.2}$$

类似地，对于反射电场 $E^{(r)}$，以反射角 $q_r$ 有：

$$E_x^{(r)} = -E_p^{(r)}\cos q_r, \quad E_y^{(r)} = E_s^{(r)}, \quad E_z^{(r)} = -E_p^{(r)}\sin q_r \tag{6.3}$$

$E^{(r)}$ 与 $E^{(i)}$ 之间的关系由菲涅耳反射系数表达：

$$E_s^{(r)} = \frac{n_1\cos q_i - n_2\cos q_t}{n_1\cos q_i + n_2\cos q_t}E_s^{(i)}, \quad E_p^{(r)} = \frac{n_2\cos q_i - n_1\cos q_t}{n_2\cos q_i + n_1\cos q_t}E_p^{(i)} \tag{6.4}$$

其中 $n_1$ 与 $n_2$ 为入射介质与下层介质的折射率，$q_t$ 为折射角。

表面电场 $E^{(\text{surf})}$ 由以下 Fresnel 系数给出：

$$E_x^{(\text{surf})} = \frac{2n_1\cos q_i \cos q_t}{n_2\cos q_i + n_1\cos q_t}E_p^{(i)} \tag{6.5a}$$

$$E_y^{(\text{surf})} = \frac{2n_1\cos q_i}{n_1\cos q_i + n_2\cos q_t}E_s^{(i)} \tag{6.5b}$$

$$E_z^{(\text{surf})} = -\frac{2n_1\cos q_i \sin q_t}{n_2\cos q_i + n_1\cos q_t}\left(\frac{n_1 n_2}{n'}\right)^2 E_p^{(i)} \tag{6.5c}$$

式 $(6.5c)$ 中的 $n'$ 为 SFG 辐射发生处的界面层折射率。

将上述表面电场分量 $(6.5)$ 代入式 $(6.1)$ 中，即可得到矢量形式的表面极化强度。

## 7. SFG输出与SFG电场

由分极强度 $P(\omega_{\text{SF}})$ 产生的 SFG 电场 $E(\omega_{\text{SF}})$ 分为"反射型"和"透射型"两束输出。分别以反射侧 SFG 电场 $E^{(r)}(\omega_{\text{SF}})$ 和透射侧 SFG 电场 $E^{(t)}(\omega_{\text{SF}})$ 表示，其表达式为：

$$E_s^{(r)}(\omega_{\text{SF}}) = \frac{4\pi i\omega_{\text{SF}}}{c}\frac{P_y(\omega_{\text{SF}})}{n_1\cos q_i + n_2\cos q_t} \tag{7.1a}$$

$$E_p^{(r)}(\omega_{\text{SF}}) = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{P_x(\omega_{\text{SF}})\cos q_t - \left(\frac{n_2}{n'}\right)^2 P_z(\omega_{\text{SF}})\sin q_t}{n_2\cos q_i + n_1\cos q_t} \tag{7.1b}$$

$$E_s^{(t)}(\omega_{\text{SF}}) = \frac{4\pi i\omega_{\text{SF}}}{c}\frac{P_y(\omega_{\text{SF}})}{n_1\cos q_i + n_2\cos q_t} \tag{7.2a}$$

$$E_p^{(t)}(\omega_{\text{SF}}) = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{P_x(\omega_{\text{SF}})\cos q_i + \left(\frac{n_1}{n'}\right)^2 P_z(\omega_{\text{SF}})\sin q_i}{n_2\cos q_i + n_1\cos q_t} \tag{7.2b}$$

上述关系也可用张量形式的传递函数表达。将大写字母 $L$ 定义为各分量的传递因子，则有：

$$E_s^{(r)}(\omega_{\text{SF}}) = L_{s,y}^{(r)}P_y(\omega_{\text{SF}}), \quad E_p^{(r)}(\omega_{\text{SF}}) = L_{p,x}^{(r)}P_x(\omega_{\text{SF}}) + L_{p,z}^{(r)}P_z(\omega_{\text{SF}}) \tag{7.3a}$$

$$E_s^{(t)}(\omega_{\text{SF}}) = L_{s,y}^{(t)}P_y(\omega_{\text{SF}}), \quad E_p^{(t)}(\omega_{\text{SF}}) = L_{p,x}^{(t)}P_x(\omega_{\text{SF}}) + L_{p,z}^{(t)}P_z(\omega_{\text{SF}}) \tag{7.3b}$$

其中：

$$L_{s,y}^{(r)} = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{1}{n_1\cos q_i + n_2\cos q_t} \tag{7.4a}$$

$$L_{p,x}^{(r)} = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{\cos q_t}{n_2\cos q_i + n_1\cos q_t} \tag{7.4b}$$

$$L_{p,z}^{(r)} = \frac{4\pi i\omega_{\text{SF}}}{c}\frac{\left(\frac{n_2}{n'}\right)^2 P_z(\omega_{\text{SF}})\sin q_t}{n_2\cos q_i + n_1\cos q_t} \tag{7.4c}$$

$$L_{s,y}^{(t)} = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{1}{n_1\cos q_i + n_2\cos q_t} \tag{7.5a}$$

$$L_{p,x}^{(t)} = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{\cos q_i}{n_2\cos q_i + n_1\cos q_t} \tag{7.5b}$$

$$L_{p,z}^{(t)} = -\frac{4\pi i\omega_{\text{SF}}}{c}\frac{\left(\frac{n_1}{n'}\right)^2 P_z(\omega_{\text{SF}})\sin q_i}{n_2\cos q_i + n_1\cos q_t} \tag{7.5c}$$

其中，式 $(7.1b)$ 以及式 $(7.4b)$ 中出现了 $z$ 分量与 $x$ 分量的耦合项，这是因为 SFG 辐射在界面处的折射导致了 $s$ 偏振分量的混合效应。
