## 弯曲振动 SFG张量：从实验室 (xyz) 系到空间固定 (XYZ) 系的变换

SFG张量在实验室 (xyz) 坐标系中得出后，弯曲振动的张量需要变换到空间固定 (XYZ) 坐标系中。以下列出变换后的结果。

实验室 (xyz) 系的z轴沿表面法线方向（指向外侧）。x轴沿特定的面内方向（对于CH2和HCCH，x轴取含2个CH键的面的取向方向）。空间固定 (XYZ) 系通过绕 (xyz) 系的z轴旋转c角得到，详见文件"旋转矩阵 (xyz).doc"中的说明（取 $f = 0, q = 0$ 并写成简洁形式）。

---

### 弯曲振动各偏振组合的SFG张量元变换公式

#### (ppp) 组合

$$
\begin{aligned}
c_{XXX} &= -\frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\cos c - \cos 3c) + c_{xxx}\cos c \\
&\quad -\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\sin c + \sin 3c) + c_{yyy}\sin c \\[4pt]
c_{XZZ} &= c_{xzz}\cos c + c_{yzz}\sin c \\[4pt]
c_{ZXZ} &= c_{zxz}\cos c + c_{zyz}\sin c \\[4pt]
c_{ZZX} &= c_{zzx}\cos c + c_{zzy}\sin c \\[4pt]
c_{ZXX} &= \frac{1}{2}[(c_{zxx} + c_{zyy}) + (c_{zxx} - c_{zyy})\cos 2c] + \frac{1}{2}(c_{zxy} + c_{zyx})\sin 2c \\[4pt]
c_{XZX} &= \frac{1}{2}[(c_{xzx} + c_{yzy}) + (c_{xzx} - c_{yzy})\cos 2c] + \frac{1}{2}(c_{yzx} + c_{xzy})\sin 2c \\[4pt]
c_{XXZ} &= \frac{1}{2}[(c_{xxz} + c_{yyz}) + (c_{xxz} - c_{yyz})\cos 2c] + \frac{1}{2}(c_{xyz} + c_{yxz})\sin 2c \\[4pt]
c_{ZZZ} &= c_{zzz}
\end{aligned}
$$

#### (spp) 组合

$$
\begin{aligned}
c_{YXX} &= -\frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\sin c + \sin 3c) - c_{xyy}\sin c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\cos c - \cos 3c) + c_{yxx}\cos c \\[4pt]
c_{YZZ} &= -c_{xzz}\sin c + c_{yzz}\cos c \\[4pt]
c_{YZX} &= -\frac{1}{2}(c_{xzx} - c_{yzy})\sin 2c + \frac{1}{2}[(c_{yzx} - c_{xzy}) + (c_{yzx} + c_{xzy})\cos 2c] \\[4pt]
c_{YXZ} &= -\frac{1}{2}(c_{xxz} - c_{yyz})\sin 2c + \frac{1}{2}[(c_{yxz} - c_{xyz}) + (c_{yxz} + c_{xyz})\cos 2c]
\end{aligned}
$$

#### (ssp) 组合

$$
\begin{aligned}
c_{YYX} &= \frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\cos c - \cos 3c) + c_{yyx}\cos c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\sin c + \sin 3c) + c_{xxy}\sin c \\[4pt]
c_{YYZ} &= \frac{1}{2}[(c_{xxz} + c_{yyz}) - (c_{xxz} - c_{yyz})\cos 2c] - \frac{1}{2}(c_{xyz} + c_{yxz})\sin 2c
\end{aligned}
$$

#### (psp) 组合

$$
\begin{aligned}
c_{XYX} &= -\frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\sin c + \sin 3c) - c_{yxy}\sin c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\cos c - \cos 3c) + c_{xyx}\cos c \\[4pt]
c_{ZYZ} &= -c_{zxz}\sin c + c_{zyz}\cos c \\[4pt]
c_{XYZ} &= -\frac{1}{2}(c_{xxz} - c_{yyz})\sin 2c + \frac{1}{2}[(c_{xyz} - c_{yxz}) + (c_{xyz} + c_{yxz})\cos 2c] \\[4pt]
c_{ZYX} &= -\frac{1}{2}(c_{zxx} - c_{zyy})\sin 2c + \frac{1}{2}[(c_{zyx} - c_{zxy}) + (c_{zyx} + c_{zxy})\cos 2c]
\end{aligned}
$$

#### (sps) 组合

$$
\begin{aligned}
c_{YXY} &= \frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\cos c - \cos 3c) + c_{yxy}\cos c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\sin c + \sin 3c) + c_{xyx}\sin c \\[4pt]
c_{YZY} &= \frac{1}{2}[(c_{xzx} + c_{yzy}) - (c_{xzx} - c_{yzy})\cos 2c] - \frac{1}{2}(c_{yzx} + c_{xzy})\sin 2c
\end{aligned}
$$

#### (pps) 组合

$$
\begin{aligned}
c_{XXY} &= -\frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\sin c + \sin 3c) - c_{yyx}\sin c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\cos c - \cos 3c) + c_{xxy}\cos c \\[4pt]
c_{ZZY} &= -c_{zzx}\sin c + c_{zzy}\cos c \\[4pt]
c_{ZXY} &= -\frac{1}{2}(c_{zxx} - c_{zyy})\sin 2c + \frac{1}{2}[(c_{zxy} - c_{zyx}) + (c_{zxy} + c_{zyx})\cos 2c] \\[4pt]
c_{XZY} &= -\frac{1}{2}(c_{xzx} - c_{yzy})\sin 2c + \frac{1}{2}[(c_{xzy} - c_{yzx}) + (c_{xzy} + c_{yzx})\cos 2c]
\end{aligned}
$$

#### (pss) 组合

$$
\begin{aligned}
c_{XYY} &= \frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\cos c - \cos 3c) + c_{xyy}\cos c \\
&\quad +\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\sin c + \sin 3c) + c_{yxx}\sin c \\[4pt]
c_{ZYY} &= \frac{1}{2}[(c_{zxx} + c_{zyy}) - (c_{zxx} - c_{zyy})\cos 2c] - \frac{1}{2}(c_{zxy} + c_{zyx})\sin 2c
\end{aligned}
$$

#### (sss) 组合

$$
\begin{aligned}
c_{YYY} &= \frac{1}{4}(c_{xxx} - c_{yyx} - c_{xyy} - c_{yxy})(\sin c + \sin 3c) - c_{xxx}\sin c \\
&\quad -\frac{1}{4}(c_{yyy} - c_{xxy} - c_{xyx} - c_{yxx})(\cos c - \cos 3c) + c_{yyy}\cos c
\end{aligned}
$$

---

## 说明

以上公式给出了弯曲振动（变角振动）的SFG张量从实验室 $(xyz)$ 坐标系到空间固定 $(XYZ)$ 坐标系的完整变换关系。这些公式适用于所有8种偏振组合（ppp, spp, ssp, psp, sps, pps, pss, sss），涵盖了全部27个张量元中非零分量的变换。

变换的核心参数是绕z轴的面内旋转角 $c$（即方位角）。当 $c = 0$ 时，$(XYZ)$ 系与 $(xyz)$ 系一致。

这些公式与4.9节中C-H伸缩振动的SFG张量变换公式具有相同的数学结构，区别仅在于所使用的 $(xyz)$ 系张量元 $c_{ijk}$ 的具体表达式不同——伸缩振动使用的是 $c_{ijk}^{(\text{stretch})}$ 而弯曲振动使用的是 $c_{ijk}^{(\text{bend})}$。

弯曲振动的 $(xyz)$ 系张量元 $c_{ijk}^{(\text{bend})}$ 由4.10节中的欧拉角方法确定，代入本节公式即可得到最终的实验可观测SFG强度表达式。
