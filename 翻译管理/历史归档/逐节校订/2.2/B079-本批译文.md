## 附录C. 波的传播

设光为平面波；除有必要的情况外，将入射振幅取为1。沿波传播方向取 $z$ 轴，波表示为

$$
\cos(kz-\omega t).\tag{C.1}
$$

### 单一且均匀的介质

“波位于 $(z_0,t_0)$”意指时空点 $(z_0,t_0)$ 的相位 $kz_0-\omega t_0=0$。在同一时刻 $t_0$，点 $z=z_0-\Delta z$ 的相位为 $-k\Delta z$。由 $kz-\omega t=0$，在 $t=t_0+\Delta t$ 时，波前到达 $z=z_0+(\omega/k)\Delta t$。

若沿光路分布着波源，则 $z_0-\Delta z$ 处的波源在 $t_0-\Delta z/(\omega/k)$ 时刻产生的光，传播至 $(z_0,t_0)$ 时，与该点新产生的光完全重合，即相位相同。时空点 $(z_0-\Delta z,t_0-\Delta t)$ 的相位为 $-k\Delta z+\omega\Delta t$。

### 两种介质组成的体系

设界面为平面，光由介质1侧入射介质2。定义：

| 量 | 定义 |
|---|---|
| 原点 | 入射点；光束有宽度时取其中央 |
| $z$ 轴 | 从介质1指向介质2的界面法线 |
| $x$ 轴 | 光沿界面的传播方向，与波矢在界面上的投影一致 |
| $\theta_i$ | 底本定义为入射光线与外向法线（$-z$）的夹角，$0<\theta_i<\pi/2$ |
| $\theta_r$ | 反射光线与外向法线（$-z$）的夹角，$0<\theta_r<\pi/2$ |
| $\theta_t$ | 透射光线与内向法线（$+z$）的夹角，$0<\theta_t<\pi/2$ |
| $n_1,n_2$；$k_1,k_2$ | 两介质的折射率与波矢长度；$k=n\omega/c$ |

由斯涅尔定律，令 $\theta_i=\theta_r=\theta_1$、$\theta_t=\theta_2$，有 $n_1\sin\theta_1=n_2\sin\theta_2$，亦即 $k_1\sin\theta_1=k_2\sin\theta_2$。

对于平面波，垂直于传播方向的平面上各点电场同相；沿传播方向相邻等相位面的间距为波长 $\lambda=2\pi/k=2\pi c/(\omega n)$。

设原点电场为 $E_0e^{-i\omega t}$。先追踪通过介质2中 $(x,z)$ 点的光：

| 步骤 | 光路、相位与时间 |
|---|---|
| （1） | 入射到界面的位置为 $(x-z\tan\theta_2,0)$。 |
| （1a） | 同一时刻，该点的光比原点入射光沿光路超前 $(x-z\tan\theta_2)\sin\theta_1$，相位超前 $k_1(x-z\tan\theta_2)\sin\theta_1$。 |
| （1b） | 与原点同相的波在 $t$ 之后 $(x-z\tan\theta_2)\sin\theta_1/(\omega/k_1)$ 通过该点。 |
| （2） | 在介质2中到达 $(x,z)$ 的距离为 $z/\cos\theta_2$。 |
| （2a） | 相对于入射界面时，相位前进 $k_2z/\cos\theta_2$。 |
| （2b） | 底本写到达该点的经历时间为 $\omega z/(k_2\cos\theta_2)$。 |
| （2c） | 结合（1a）及斯涅尔定律，相对于原点光的相位 $-\omega t$，总相位前进 $k_2(x\sin\theta_2+z\cos\theta_2)$。 |

再追踪通过介质1侧 $(x,-z)$、$z>0$ 的反射光：

| 步骤 | 光路、相位与时间 |
|---|---|
| （3） | 入射位置为 $(x-z\tan\theta_1,0)$。 |
| （3a） | 同时刻的光路超前量为 $(x-z\tan\theta_1)\sin\theta_1$，相位超前量为 $k_1(x-z\tan\theta_1)\sin\theta_1$。 |
| （3b） | 与原点同相的波，在 $t$ 之后 $(x-z\tan\theta_1)\sin\theta_1/(\omega/k_1)$ 通过该点。 |
| （4） | 反射后的传播距离为 $z/\cos\theta_1$。 |
| （4a） | 相对于界面反射时，相位前进 $k_1z/\cos\theta_1$；底本此处位置写作 $(x,z)$。 |
| （4b） | 底本给出的经历时间为 $\omega z/(k_1\cos\theta_1)$，位置也写作 $(x,z)$。 |
| （4c） | 结合（3a），相对于原点相位 $-\omega t$，相位前进 $k_1(x\sin\theta_1+z\cos\theta_1)$。 |

> **译校注（Q056，保留原式）：** （2b）、（4b）的时间式按量纲疑应为 $k_jz/(\omega\cos\theta_j)$，底本反写为 $\omega z/(k_j\cos\theta_j)$。反射段先取 $(x,-z)$，随后又写 $(x,z)$，这里保留并标出；入射角“光线”与外法线的夹角也须区分光线几何与传播矢量方向。
