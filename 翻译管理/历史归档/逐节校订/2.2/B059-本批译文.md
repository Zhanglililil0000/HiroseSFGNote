## 2. 准备

设介质1（入射侧）与介质2之间夹有厚度为 $h_m$ 的薄膜 $m$，两个界面均为平面且相互平行。坐标定义如下：

- 原点：取光线的入射点；若光束有一定展宽，则取其中央。
- $z$ 轴：沿从介质1指向介质2的界面法线。
- $x$ 轴：沿界面上观察到的光传播方向，即波矢在界面上的投影方向。

术语与符号定义如下：

| 符号 | 本文定义 |
|---|---|
| $1/m$ 界面 | 介质1与薄膜的界面。 |
| $m/2$ 界面 | 介质2与薄膜的界面。 |
| $n_1,n_2,n_m$ | 介质1、介质2和薄膜 $m$ 的折射率。 |
| $k_1,k_2,k_m$ | 相应介质中的波矢。 |
| $\theta_1,\theta_2,\theta_m$ | 相应介质中光路与界面法线的夹角。 |
| $t_{1m}$ | 从介质1侧透射至薄膜侧的光电场透射系数。 |
| $t_{m1}$ | 从薄膜侧透射至介质1侧的光电场透射系数。 |
| $r_{1m}$ | 从介质1侧射来，在 $1/m$ 界面反射的光电场反射系数。 |
| $r_{m1}$ | 从薄膜侧射来，在 $m/1$ 界面反射的光电场反射系数。 |
| $t_{m2}$ | 从薄膜侧透射至介质2侧的光电场透射系数。 |
| $t_{2m}$ | 从介质2侧透射至薄膜侧的光电场透射系数。 |
| $r_{m2}$ | 从薄膜侧射来，在 $m/2$ 界面反射的光电场反射系数。 |
| $r_{2m}$ | 从介质2侧射来，在 $1/m$ 界面反射的光电场反射系数（此界面名按底本保留，见下注）。 |

> **译者注（原界面名待核验 E-2.2-001；Q039）：** 底本第2页 $r_{2m}$ 的说明确写“从介质2侧射来，在1/m界面反射”。按本段的叠层和下标定义，界面名的候选修正为“2/m”；旧译已采用该修正，本轮按用户约定恢复底本文字，候选仅保留在本注，未视为已确认勘误。

- **上行（−）光：** 从 $m/2$ 界面朝 $m/1$ 界面行进，与反射光一样向 $-z$ 侧传播。
- **下行（＋）光：** 从 $m/1$ 界面朝 $m/2$ 界面行进，与入射光一样向 $+z$ 侧传播。

反射系数与透射系数的表达式见附录A。

> **译者注（局部约定）：** 此处 $r,t$ 都是光电场的振幅系数，不直接等同功率反射率或透射率。上下行标签与第2.1节一致，但与第1.3节辐射上标的侧别对应不同；本节另明确给出了 $z$ 方向。后续公式中的约定须逐批核验，不能从这份定义表推定全部公式已经相容。
