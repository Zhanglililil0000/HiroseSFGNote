# B023：附录B分批校订



当入射光为双波长时，一阶近似表现为各成分之和，而在二阶及以上近似中会引入交叉项。在二阶近似中，需解以下微分方程：

$$
\begin{aligned}
&\dot{c}(t)_{n,n}^{(2)} = -\frac{i}{\hbar} \sum_{m \neq n} c(t)_{m,n}^{(1)} r_{nm} \bigl[ \bigl( e^{i(\omega_1 - \omega_{mn})t} + e^{-i(\omega_1 + \omega_{mn})t} \bigr) + \bigl( e^{i(\omega_2 - \omega_{mn})t} + e^{-i(\omega_2 + \omega_{mn})t} \bigr) \bigr]\\[6pt]
&= \frac{i}{\hbar^2} \sum_{m \neq n} r_{nm} r_{mn} \Bigg\{ \bigl[ \bigl( \frac{1 + e^{2i\omega_1 t}}{\omega_1 + \omega_{mn}} - \frac{1 + e^{-2i\omega_1 t}}{\omega_1 - \omega_{mn}} \bigr) + \bigl( \frac{1 + e^{2i\omega_2 t}}{\omega_2 + \omega_{mn}}\\[6pt]
&- \frac{1 + e^{-2i\omega_2 t}}{\omega_2 - \omega_{mn}} \bigr) \bigr]\\[6pt]
&\quad - \frac{e^{-i(\omega_1 - \omega_2)t} + e^{-i(\omega_1 + \omega_2)t}}{\omega_1 - \omega_{mn}} - \frac{e^{i(\omega_1 - \omega_2)t} + e^{-i(\omega_1 + \omega_2)t}}{\omega_2 - \omega_{mn}}\\[6pt]
&\quad + \frac{e^{i(\omega_1 - \omega_2)t} + e^{i(\omega_1 + \omega_2)t}}{\omega_1 + \omega_{mn}} + \frac{e^{-i(\omega_1 - \omega_2)t} + e^{i(\omega_1 + \omega_2)t}}{\omega_2 + \omega_{mn}} \Bigg\}, \quad (\omega_1, \omega_2 \neq \omega_{nm})
\end{aligned}
\tag{B-8}
$$

$$
\begin{aligned}
&\dot{c}(t)_{l,n}^{(2)} = \frac{i}{\hbar^2} \sum_{m \neq n} r_{lm} r_{mn} \Bigg\{ e^{i\omega_{ln}t} \bigl[ \frac{1 + e^{2i\omega_1 t}}{\omega_1 + \omega_{mn}} - \frac{1 + e^{-2i\omega_1 t}}{\omega_1 - \omega_{mn}}\\[6pt]
&+ \frac{1 + e^{2i\omega_2 t}}{\omega_2 + \omega_{mn}} - \frac{1 + e^{-2i\omega_2 t}}{\omega_2 - \omega_{mn}} \bigr]\\[6pt]
&\quad + e^{i\omega_{ml}t} \Bigg[ \frac{e^{i(\omega_1 + \omega_2)t} + e^{i(\omega_1 - \omega_2)t}}{\omega_1 + \omega_{mn}} + \frac{e^{i(\omega_1 + \omega_2)t} + e^{-i(\omega_1 - \omega_2)t}}{\omega_2 + \omega_{mn}}\\[6pt]
&\quad - \frac{e^{-i(\omega_1 + \omega_2)t} + e^{-i(\omega_1 - \omega_2)t}}{\omega_1 - \omega_{mn}} - \frac{e^{-i(\omega_1 + \omega_2)t} + e^{i(\omega_1 - \omega_2)t}}{\omega_2 - \omega_{mn}} \Bigg] \Bigg\}, \quad (l \neq n, \omega \neq \omega_{mn}, \omega \neq \omega_{lm})
\end{aligned}
\tag{B-9}
$$
