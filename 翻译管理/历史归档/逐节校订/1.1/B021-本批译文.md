# B021：附录A分批校订

**（二阶近似）**

$$
\begin{aligned}
&p(t)^{(2)} = \sum_{m \neq n} \bigl( c(t)_{m,n}^{(2)} r_{nm} + c(t)_{m,n}^{(2)*} r_{mn} \bigr) + \sum_{m,l \neq n} c(t)_{m,n}^{(1)*} c(t)_{l,n}^{(1)} r_{ml}\\[6pt]
&= \frac{1}{\hbar^2} \sum_{m,l \neq n} r_{nm} r_{ml} r_{ln} \Bigg\{ e^{i\omega_{mn}t} \Bigg[ \frac{1}{\omega_{mn} (\omega + \omega_{ln})} - \frac{1}{\omega_{mn} (\omega - \omega_{ln})}\\[6pt]
&\quad + \frac{e^{2i\omega t}}{(2\omega + \omega_{mn})(\omega + \omega_{ln})} + \frac{e^{-2i\omega t}}{(2\omega - \omega_{mn})(\omega - \omega_{ln})} \Bigg]\\[6pt]
&\quad + e^{-i\omega_{ln}t} \Bigg[ \frac{1}{\omega_{ln} (\omega + \omega_{mn})} - \frac{1}{\omega_{ln} (\omega - \omega_{mn})}\\[6pt]
&\quad + \frac{e^{2i\omega t}}{(\omega - \omega_{mn})(2\omega - \omega_{ln})} + \frac{e^{-2i\omega t}}{(\omega + \omega_{mn})(2\omega + \omega_{ln})} \Bigg]\\[6pt]
&\quad + e^{i\omega_{lm}t} \Bigg[ \frac{1}{(\omega - \omega_{mn})(\omega - \omega_{ln})} + \frac{1}{(\omega + \omega_{mn})(\omega + \omega_{ln})}\\[6pt]
&\quad - \frac{e^{2i\omega t}}{(\omega - \omega_{mn})(\omega + \omega_{ln})} - \frac{e^{-2i\omega t}}{(\omega + \omega_{mn})(\omega - \omega_{ln})} \Bigg] \Bigg\}
\end{aligned}
\tag{A-10}
$$

当入射光为双波长时，结果如下：

$$
\begin{aligned}
&p(t)^{(1)} = \frac{1}{\hbar} \sum_{m \neq n} r_{nm} r_{mn} \Bigg[ \frac{e^{i(\omega_1 - \omega_{ln})t} + e^{-i(\omega_1 - \omega_{ln})t}}{\omega_1 - \omega_{ln}} - \frac{e^{i(\omega_1 + \omega_{ln})t} + e^{-i(\omega_1 + \omega_{ln})t}}{\omega_1 + \omega_{ln}}\\[6pt]
&+ \frac{e^{i(\omega_2 - \omega_{ln})t} + e^{-i(\omega_2 - \omega_{ln})t}}{\omega_2 - \omega_{ln}} - \frac{e^{i(\omega_2 + \omega_{ln})t} + e^{-i(\omega_2 + \omega_{ln})t}}{\omega_2 + \omega_{ln}} \Bigg]
\end{aligned}
\tag{A-11}
$$

对于 $p(t)^{(2)}$，除每个波长的二倍频和直流成分外，还额外提取了交叉项，记录如下：

$$
\begin{aligned}
&p(t)^{(2)} = \text{Eq. (A-10) with } \omega \text{ replaced by } \omega_1 \text{ and } \omega_2\\[6pt]
&\quad + \frac{1}{\hbar^2} \sum_{m,l \neq n} r_{nm} r_{ml} r_{ln} e^{-i\omega_{ml}t} \Bigg\{ e^{i(\omega_1 - \omega_2)t} \Bigg[ \frac{1}{(\omega_2 + \omega_{mn})(\omega_1 + \omega_{ln})} + \frac{1}{(\omega_2 - \omega_{ln})(\omega_1 - \omega_{mn})}\\[6pt]
&\quad\quad + \frac{1}{(\omega_1 - \omega_2 - \omega_{ml})} \bigl[ -\frac{1}{(\omega_2 - \omega_{ln})} + \frac{1}{(\omega_1 + \omega_{ln})} + \frac{1}{(\omega_2 + \omega_{mn})} + \frac{1}{(\omega_1 - \omega_{mn})} \bigr] \Bigg]\\[6pt]
&\quad\quad + e^{-i(\omega_1 - \omega_2)t} \Bigg[ \frac{1}{(\omega_2 + \omega_{mn})(\omega_1 + \omega_{ln})} + \frac{1}{(\omega_1 - \omega_{ln})(\omega_2 - \omega_{mn})}\\[6pt]
&\quad\quad\quad + \frac{1}{(\omega_1 - \omega_2 + \omega_{ml})} \bigl[ \frac{1}{(\omega_2 + \omega_{ln})} + \frac{1}{(\omega_1 - \omega_{ln})} - \frac{1}{(\omega_2 - \omega_{mn})} + \frac{1}{(\omega_1 + \omega_{mn})} \bigr] \Bigg]\\[6pt]
&\quad\quad + e^{+i(\omega_1 + \omega_2)t} \Bigg[ \frac{-1}{(\omega_2 + \omega_{ln})(\omega_1 - \omega_{mn})} + \frac{-1}{(\omega_2 - \omega_{mn})(\omega_1 + \omega_{ln})}\\[6pt]
&\quad\quad\quad + \frac{1}{(\omega_1 + \omega_2 - \omega_{ml})} \bigl[ \frac{1}{(\omega_2 + \omega_{ln})} + \frac{1}{(\omega_1 + \omega_{ln})} - \frac{1}{(\omega_2 - \omega_{mn})} + \frac{1}{(\omega_1 - \omega_{mn})} \bigr] \Bigg]\\[6pt]
&\quad\quad + e^{-i(\omega_1 + \omega_2)t} \Bigg[ \frac{-1}{(\omega_2 - \omega_{ln})(\omega_1 + \omega_{mn})} + \frac{-1}{(\omega_1 - \omega_{ln})(\omega_2 + \omega_{mn})}\\[6pt]
&\quad\quad\quad + \frac{1}{(\omega_1 + \omega_2 + \omega_{ml})} \bigl[ \frac{1}{(\omega_2 - \omega_{ln})} + \frac{1}{(\omega_1 - \omega_{ln})} - \frac{1}{(\omega_2 + \omega_{mn})} + \frac{1}{(\omega_1 + \omega_{mn})} \bigr] \Bigg] \Bigg\}
\end{aligned}
\tag{A-12}
$$

由上述公式可以理解极化在何种情况下会表现出共振性增强。
