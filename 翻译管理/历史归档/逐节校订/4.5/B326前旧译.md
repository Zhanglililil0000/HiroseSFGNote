## 1. 绪论

下面考察含两个甲基的分子，其CH伸缩振动所对应的和频张量。典型例子包括丙酮、二甲醚等两个甲基连接在同一原子上的分子，以及丁烯、二甲基乙炔。此外，对于从同一个原子伸出两条烷基链的分子，如果末端甲基因某种原因保持一定的相对取向，这里给出的结果也应当适用。

假定甲基具有$C_{3v}$对称性。以$(\mathrm{CH}_3)_2\mathrm X$基团为模型时，若甲基内部自由旋转，体系具有$C_{2v}$对称性。由于可以回到振动矢量的层面考察和频张量，即使两个甲基在空间上相互分离，也允许在模型中将其视为$(\mathrm{CH}_3)_2\mathrm X$基团来讨论。


## 2. 坐标系与甲基取向

**(1) 甲基固定坐标系——$(abc)$系：** 沿$C_3$轴取$c$轴，正方向由C原子指向H原子，并使三个CH键中的一个位于$ac$面内。

**(2) $(\mathrm{CH}_3)_2\mathrm X$基团固定坐标系——$(xyz)$系：** 沿两个甲基$C_3$轴的角平分线取$z$轴，从X原子指向甲基的方向为正。在两个$C_3$轴所成的平面内取$x$轴。

**(3) 甲基取向：** 令$z$轴与甲基$C_3$轴之间的夹角（即CXC角的一半）为$\alpha$。用下标A、B区分两个甲基，分别以$\phi_A$、$\phi_B$表示其内部旋转角。以甲基三个H原子构成的正三角形有一个顶点朝向表面的状态为基准，此时内部旋转角为$\phi_A=0$、$\phi_B=0$。正三角形的一条边靠近表面时，内部旋转角为$180^\circ$。CH键位于CXC面内锐角一侧的状态为$\phi=0$，位于钝角一侧的状态为$\phi=\pi$。

只有“简并振动”谱带的和频张量会因内部旋转角不同而产生差异。因此，可以通过简并谱带的表现了解甲基的相对取向及旋转情况。

**(4) 欧拉角——$(\chi,\theta,\phi)$：** 设CXC角为$2\alpha$，将两个甲基的坐标系分别与分子固定系重合时，欧拉角为$(0,\alpha,\phi)$及$(\pi,\alpha,\phi)$（据此确定$b$轴的方向）。

> **译者注（坐标层级）：** 本段变换是从甲基固定$(abc)$系到基团固定$(xyz)$系，尚不是第6部分的空间固定$(XYZ)$系变换。原欧拉角三元组中的$\phi$未分别加A、B下标，按原写保留；需要区分两个甲基时，使用前段定义的$\phi_A,\phi_B$。

按照上述定义求得的张量分量一般式列于附录A。可以看出，简并谱带的表达式依赖内部旋转角。关于倾斜角$\theta$，不采用表中$\sin\theta$、$\sin2\theta$、$\sin3\theta$形式的三角函数，而是利用下列关系，改写为$\sin\theta$、$\cos\theta$的幂：

$$
\begin{aligned}
\sin2\theta&=2\sin\theta\cos\theta,\\
\cos2\theta&=\cos^2\theta-\sin^2\theta
=2\cos^2\theta-1=1-2\sin^2\theta,\\
\sin3\theta&=3\sin\theta-4\sin^3\theta,\\
\sin\theta+\sin3\theta&=4(\sin\theta-\sin^3\theta),\\
\cos3\theta&=4\cos^3\theta-3\cos\theta,\\
\cos\theta-\cos3\theta&=4(\cos\theta-\cos^3\theta).
\end{aligned}
$$

正文将列出几种典型相对取向下$(xyz)$系中的张量分量。作为$(\mathrm{CH}_3)_2\mathrm X$基团，其对称性随两个甲基的相对取向而改变。


## 3. 振动谱带

对于两个甲基组成$(\mathrm{CH}_3)_2\mathrm X$型基团的情况，甲基全对称模式与简并模式的行为可整理如下。

**(1) 全对称振动：** 两个CH₃基团各自具有的全对称振动模式相互组合，形成同相振动的对称振动和反相振动的反对称振动。前者沿$z$轴，后者沿$x$轴，两者均为CXC面内振动。不过，当CXC角为$0$或$\pi$，即$\alpha=0$或$\pi/2$时，则成为$x$轴方向的对称振动与反对称振动。

**(2) 简并振动：** 每个CH₃基团的简并振动自由度为2，因此组成$(\mathrm{CH}_3)_2\mathrm X$型基团时，振动自由度为4。在甲基固定$(abc)$坐标系中，简并振动由$a$轴方向和$b$轴方向的振动构成。对于两个CH₃基团组成的体系，两个$a$轴方向振动相互组合，同相振动成为沿$z$轴的振动，反相振动成为沿$x$轴的振动。这两个模式均位于分子面内。当$\alpha=0$或$\pi/2$时，则成为绕$y$轴、即相对于CXC轴同向弯折和反向弯折的两种振动运动。

另一方面，由一对$a$轴方向振动形成的同相振动，成为垂直于分子面的$y$轴方向振动；反相振动则成为绕CXC角平分线的扭转振动。当$(\mathrm{CH}_3)_2\mathrm X$具有$C_{2v}$对称性时，该扭转振动属于对红外吸收和拉曼散射均不活性的$a_2$对称种，其振动矢量不沿三个坐标轴中的任何一个方向（成为轴矢量）。当$\alpha=0$或$\pi/2$时，与上文所述$a$轴方向振动的情况类似，但振动方向与上文垂直。

后续推导排除两个甲基沿一直线排列的情况，即两条$C_3$轴位于同一直线上、$\alpha=0$或$\pi/2$的情况。这一点也可从CXC部分的对称性由$C_{2v}$变为$D_{\infty h}$预见，因为相应讨论几乎会增加一倍。

> **译者注（原文疑点Q169，PDF p2—3）：** 原文先述$a$轴振动对产生面内模式，下一段又写“$a$轴方向”，却得到面外及扭转模式；后一处候选为$b$轴，未采用。全对称振动在两个极限角均归为$x$轴方向，以及两个共线极限均归为$D_{\infty h}$的原述也保留，需分别检查坐标退化及极限几何；本轮不为原文补写极限推导。四个自由度不等于四个模式仍然简并，原文所说的弯折/扭转组合也不能据此将本节CH伸缩主题改为弯曲振动。

## 4. (CH₃)₂X基团的对称性

即使CXC部分呈弯折结构，$(\mathrm{CH}_3)_2\mathrm X$基团的对称性仍随甲基的内部旋转角不同而分为以下情况：

| 内部旋转条件 | 原文给出的对称性 |
|---|---|
| 自由旋转 | $C_{2v}$ |
| $\phi_A=\phi_B=0$或$\pi$ | $C_{2v}$ |
| $\phi_A=\phi_B\ne0$或$\pi$ | $C_2$（$z$轴） |
| $\phi_A=0,\phi_B=\pi$或$\phi_A=\pi,\phi_B=0$ | $C_s$（$xz$面） |
| $\phi_A=-\phi_B\ne0$ | $C_s$（$yz$面） |
| $\phi_A\ne\pm\phi_B$ | 无对称性（$C_1$对称；或许以$C_{3v}^{A}\times C_{3v}^{B}$型的乘积表示才正确） |

（若要严格处理，采用置换—旋转群进行分析和分类更为合适，参见Bunker的教科书。）

> **译者注（原文疑点Q170，PDF p1、p3）：** 第4部分等角条件原写“$\phi_A=\phi_B\ne0$或$\pi$”，与目录的$\ne0,\pi$写法不同，按原保留，不能读成将等于$\pi$同时归入此行。反号条件此处仅排除$0$，目录还排除$\pi$，差异保留待核。乘积表示的陈述以及严格群论处理的建议均保留作者原有的推测语气，不当作已完成的分类证明。

## 5. 分子坐标系中的SFG张量 —— 三种情况

根据扭转角fA和fB的不同组合，SFG张量分为不同情况讨论。

### 伸缩振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_aac ~ (4/9) b_zzz, b_ccc ~ (1/9) b_zzz。

#### 情况 fA = fB = 0, p（全对称，等价于2个重叠——2个eclipsed）

当fA = fB = 0时：cos(fA) = cos(fB) = cos(2fA) = cos(2fB) = cos(3fA) = cos(3fB) = +1

当fA = fB = p时：cos(fA) = cos(fB) = cos(3fA) = cos(3fB) = -1, cos(2fA) = cos(2fB) = +1

**(a1) 对称性：**

```
b_xxz = -2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_aac cos a
b_yyz = +2 b_aac cos a
b_zzz = +2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_ccc cos a
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

**(b1) 对称性：**

```
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

### 弯曲振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

注意：zyy和yzy属于b类弯曲振动，与a类弯曲振动符号相反。

#### 情况 fA = fB = 0（或 fA = fB = p）

**(a1) 对称性：**

```
b_xxz = -2 b_caa (cos a - cos 3a)
b_yyz = 0
b_zzz = 2 b_caa (cos a - cos 3a)
```

**(b1) 对称性：**

```
b_zxx = -b_caa (cos a - 2cos 3a)
b_xzx = -b_caa (cos a - 2cos 3a)
```

**(b2) 对称性：**

```
b_zyy = b_caa cos a
b_yzy = b_caa cos a
```

#### 情况 fA = fB != 0, p（2个eclipsed，取向一致）

此时 sin(n*fB) = -sin(n*fA), cos(n*fB) = cos(n*fA)。

**伸缩振动模式（a1和b1）：** 与上述fA = fB = 0, p情况下的表达式相同。

**弯曲振动模式：**

第三组分量（b类弯曲，a类弯曲符号相反）中，需注意a类弯曲振动与b类弯曲振动的区别。其中，需注意a类弯曲振动与b类弯曲振动具有不同的符号关系。

```
b_zxx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_xzx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_zyy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]
b_yzy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]

b_zzz = 2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa sin 3a (cos 3fA - cos fA)
```

```
b_yzx = -(1/2) b_caa cos 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_zyx = -(1/2) b_caa cos 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
```

## 6. 实验室坐标系(XYZ)中的SFG张量

分子坐标系(xyz)中的张量通过欧拉角(c, q, f)变换到实验室坐标系(XYZ)，最终得到实验上可观测的SFG张量。由于变换较为复杂，这里汇总了前面各情况（类型A）的完整表达式，并扩展到所有取向分布情况（类型B至类型F）。

一般地，利用欧拉角将(CH3)2X分子取向变换到实验室坐标系，各参数的定义如下：

### (1) 扭转角f

CXC角（即骨架角）决定了f的可能取值。c轴方向需要关注两个甲基之间的取向角，因此分子面内的ab面相对于X轴的方向决定了扭转角的取值。当Z轴与c轴一致时，X原子在y方向上使CXC角产生面内的偏转角（< 90度）。（x方向的矢量与X方向的矢量之间的夹角由面内取向决定。）

(a) 分子面沿z轴方向无倾斜时：f = 0 或 p；CXC面沿z轴方向倾斜时则为 f = pi/2 或 3pi/2。

(b) 双甲基中存在两个甲基，A甲基的扭转角为f，(CH3)2X中B甲基的扭转角为-f。

(c) (CH3)2X的两个甲基耦合使得取向分布产生对称性：扭转角f可取0~2pi中任意值。

### (2) 倾斜角qtilt（tilt角）

分子相对于z轴（CXC二等分线）的倾斜角通常称为tilt角。N原子沿z轴方向的倾斜由倾斜角描述。Z轴的倾斜角使用q = pi - qtilt表示。对于(CH3)2X的两个CH3基团，qtilt < pi/2。

### (3) 面内旋转角cip（in-plane）

c轴在XY面上的投影与Z轴方向的X方向的夹角为面内取向角。当Z轴与c轴一致时，X方向的面内取向产生面内偏转角。Z轴为对称轴时，欧拉角c = pi/2 + cip。

(a) 面内CXC二等分线的X方向倾斜角a，取决于具体的Y方向转角a。面内CXC二等分线方向与X方向的取向关系决定了cip = +a 或 -a的各种组合。

(b) 面内旋转角可自由取值，cip可取0~2pi内的任意值。

---

本节内容按分子对称性分类，包含了：取向无序情况、fA = fB = 0 或 p 情况、fA = fB != 0, p 情况、以及fA = 0, fB = p（或fA = p, fB = 0）情况，并对各类情况的张量分量进行了详细推导。

所有四种情况均有以下对称关系：
- 伸缩振动中：b_zxx = b_xzx
- 弯曲振动中：b_zxx = b_xzx, b_zyy = b_yzy
- （对于各情况）b_yzx = b_zyx, b_zxy = b_xzy, b_xyz = b_yxz

此外，取向无序的情况（类型B）与取向特定情况（类型C、D、E）之间存在相似性，本节对各情况的张量进行了全面的对比。在计算过程中，利用CXC面内扭转角f的对称性（当cos(nf)=0, sin(nf)=0时简化）可以进一步简化表达式。

本节将张量分为"CH3伸缩振动的SFG张量"和"CH2弯曲振动的SFG张量"两部分进行讨论。

## 类型A：(CH3)2X的SFG张量 —— 分子坐标系中各取向情况

### 分子坐标系定义

1. 分子固有坐标系：(a, b, c) 系。C3轴沿c方向，C原子和H原子构成的平面为ac面，三个CH键之一在ac面内。

2. (CH3)2X中双甲基的坐标系：(x, y, z) 系。双甲基的C3轴为z轴，X原子位于yz面内。两个甲基共享一个C3轴，x轴为二等分线方向。

3. 甲基取向角：z轴与C3轴一致，倾斜角为a（CXC角的一半）。每个甲基的A, B两个CH键的取向由扭转角fA, fB决定。甲基的三个H原子相对于三角形底面，当间隙取向时fA = 0, fB = 0。相对于三角形底面旋转180度为重叠取向。扭转角的组合决定了"伸缩振动"和"弯曲振动"对SFG张量的贡献。此时，弯曲振动与伸缩振动的耦合比是扭转角的函数，由于两种模式在取向对称性上有所不同，后续将分别讨论。

4. 欧拉角(c, q, f)：双甲基分子从分子坐标系到空间坐标系的变换。CXC角为2a，(0, a, f)和(pi, a, f)为两个甲基的欧拉角（脚底取向基准）。

张量变换的一般公式为：

```
b_ijk = sum_{a,b,c} U_{ijk:abc} * beta_{abc}  (i, j, k = x, y, z)
```

其中系数矩阵U_{ijk:abc}参考了Appl. Spectrosc.文献中的(xyz)系张量变换公式。自变量q以sin(q), sin(2q), sin(3q)等三角函数形式出现，利用前面的倍角公式可以相互转换。

### 伸缩振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_aac ~ (4/9) b_zzz, b_ccc ~ (1/9) b_zzz。

（注：此处为取向无序情况下的表达式。）

```
b_xxz = -2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_aac cos a
b_yyz = +2 b_aac cos a
b_zzz = +2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_ccc cos a
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

### 弯曲振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

（注：第三组和第四组分量分别对应a类弯曲与b类弯曲的不同情况。需注意a类弯曲振动与b类弯曲振动的区别。）

**组1：**

```
b_zxx = -(1/2) b_caa (cos a - 2 cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_xzx = -(1/2) b_caa (cos a - 2 cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_zyy = (1/2) b_caa cos a [2 - (1/2)(cos 2fA + cos 2fB)]
       - (1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (1/2)(cos fA + cos fB)]
b_yzy = (1/2) b_caa cos a [2 - (1/2)(cos 2fA + cos 2fB)]
       - (1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (1/2)(cos fA + cos fB)]
b_xxz = -b_caa (cos a - cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_yyz = -(1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_zzz = b_caa (cos a - cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa sin 3a [(cos 3fA + cos 3fB) - (cos fA + cos fB)]
```

**组2：**

```
b_yzx = -(1/2)*(1/2) b_caa cos 2a (sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (sin fA + sin fB)]
b_zyx = -(1/2)*(1/2) b_caa cos 2a (sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (sin fA + sin fB)]
b_zxy = -(1/2)*(1/2) b_caa (2 cos 2a - 1)(sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (1/2)(sin fA + sin fB)]
b_xzy = -(1/2)*(1/2) b_caa (2 cos 2a - 1)(sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (1/2)(sin fA + sin fB)]
b_xyz = (1/2) b_caa sin 2a (sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (sin fA + sin fB)]
b_yxz = (1/2) b_caa sin 2a (sin 2fA + sin 2fB)
       - (1/2) b_aaa sin a cos a [(sin 3fA + sin 3fB) - (sin fA + sin fB)]
```

**组3：**

```
b_xxx = -(1/2) b_caa (sin a - sin 3a)(cos 2fA - cos 2fB)
       - (1/2) b_aaa (cos a - cos 3a)[(cos 3fA - cos 3fB) - (cos fA - cos fB)]
b_yyx = -(1/2) b_aaa (cos a - cos 3a)[(cos 3fA - cos 3fB) - (cos fA - cos fB)]
b_zzx = b_caa (sin a - sin 3a)(cos 2fA - cos 2fB)
       + (1/2) b_aaa (cos a - cos 3a)[(cos 3fA - cos 3fB) - (cos fA - cos fB)]
b_xyy = (1/2) b_caa sin a (cos 2fA - cos 2fB)
       - (1/2) b_aaa cos a [(cos 3fA - cos 3fB) - (1/2)(cos fA - cos fB)]
b_yxy = (1/2) b_caa sin a (cos 2fA - cos 2fB)
       - (1/2) b_aaa cos a [(cos 3fA - cos 3fB) - (1/2)(cos fA - cos fB)]
b_xzz = (1/2) b_caa (sin a - 2 sin 3a)(cos 2fA - cos 2fB)
       + (1/2) b_aaa (cos a - cos 3a)[(cos 3fA - cos 3fB) - (cos fA - cos fB)]
b_zxz = (1/2) b_caa (sin a - 2 sin 3a)(cos 2fA - cos 2fB)
       + (1/2) b_aaa (cos a - cos 3a)[(cos 3fA - cos 3fB) - (cos fA - cos fB)]
```

**组4：**

```
b_yxx = (1/2) b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa cos 2a [(sin 3fA - sin 3fB) - (sin fA - sin fB)]
b_xyx = (1/2) b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa cos 2a [(sin 3fA - sin 3fB) - (sin fA - sin fB)]
b_xxy = b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa cos 2a [(sin 3fA - sin 3fB) - (1/2)(sin fA - sin fB)]
b_yyy = (1/2) b_aaa [(sin 3fA - sin 3fB) - (1/2)(sin fA - sin fB)]
b_zzy = -(1/2) b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa sin 2a [(sin 3fA - sin 3fB) - (1/2)(sin fA - sin fB)]
b_yzz = -(1/2)*(1/2) b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa sin 2a [(sin 3fA - sin 3fB) - (sin fA - sin fB)]
b_zyz = -(1/2)*(1/2) b_caa sin a cos a (sin 2fA - sin 2fB)
       - (1/2) b_aaa sin 2a [(sin 3fA - sin 3fB) - (sin fA - sin fB)]
```

## 结论

本章系统推导了(CH3)2X型双甲基分子在SFG光谱中的张量表达式。通过考虑两个甲基的不同扭转角组合(fA, fB)，将对称性区分为C2v、C2、Cs、C1等多种情况。对于每种情况，分别给出了伸缩振动模式和弯曲振动模式在分子坐标系(xyz)和实验室坐标系(XYZ)中的完整SFG张量。

主要结论如下：
1. 伸缩振动模式主要由a1对称性的zzz分量主导，zzz >> xxz, hhz。
2. 弯曲振动模式的贡献取决于两个甲基的相对扭转角，在fA = fB = 0, p时最为简单。
3. (a1)和(b1)对称性分量满足求和定则：c_XXX + c_YYX + c_ZZX = 0等。
4. 一般情况（类型F）包含最完整的表达式，涵盖了任意扭转角组合的情况。
