#### 简并谱带

当$\beta_{\zeta\zeta\zeta}\gg\beta_{\xi\xi\zeta},\beta_{\eta\eta\zeta}$时，$\beta_{caa}\sim(4/9)\beta_{\zeta\zeta\zeta}$、$\beta_{aaa}\sim(4\sqrt2/9)\beta_{\zeta\zeta\zeta}$。

<!-- source p11l04 -->

原则上，振动谱带会分裂为三个；若实际相互重叠，则应将下面三个谱带表达式相加，用于拟合测得的光谱。

<!-- source p11l06 -->

$$
\beta _{xxz} + \beta _{yyz} =- 4\beta _{caa}(\cos \alpha - \cos ^{3}\alpha ) \pm 2\beta _{aaa}\sin ^{3}\alpha
$$

<!-- source p11l07 -->

$$
\beta _{xxz} - \beta _{yyz} = -4\beta _{caa}(\cos \alpha - \cos ^{3}\alpha ) \pm 2\beta _{aaa}(2\sin \alpha + \sin ^{3}\alpha )
$$

<!-- source p11l08 -->

$$
\beta _{xxz} + \beta _{yyz} - 2\beta _{zzz} = -12\beta _{caa}(\cos \alpha - \cos ^{3}\alpha ) - (\pm )2\beta _{aaa}\sin ^{3}\alpha
$$

<!-- source p11l09 -->

$$
\beta _{zxx} = -2\beta _{caa}(\cos \alpha - 2\cos ^{3}\alpha ) - (\pm )2\beta _{aaa}(\sin \alpha - \sin ^{3}\alpha )
$$

<!-- source p11l10 -->

由于$\beta _{zyy} = 2\beta _{caa}\cos \alpha - (\pm )2\beta _{aaa}\sin \alpha$，得到：
