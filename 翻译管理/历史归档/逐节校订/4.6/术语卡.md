# 4.6局部术语卡

| 原文 | 中文 | 辨析 |
|---|---|---|
| C₃ᵥ対称が崩れた | C₃ᵥ对称性破缺 | 主题为甲基对称性降低 |
| 縮重が解ける | 简并解除 | 不译作弯曲振动 |
| モードパターン | 模式形态 | 与频率变化分开 |
| 分子内対称座標 | 分子内对称坐标 | S |
| 内部座標 | 内坐标 | R |
| 基準座標 | 简正坐标 | Q；旧译“正则坐标”改为振动分析常用表述 |
| 力の定数 | 力常数 | K1/K2与排斥参数F/F′分开 |
| バンドの分裂幅／シフト | 谱带分裂宽度／位移 | 频率ν而非本征值λ的量 |

分子和空间响应语境沿用既定术语；本节矩阵L、Ls不是菲涅尔因子。
