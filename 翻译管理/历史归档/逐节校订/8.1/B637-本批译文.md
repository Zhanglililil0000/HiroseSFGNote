## 观测光谱与分子非线性响应的联系

这里再确认实验观测到的和频光谱与分子非线性响应之间的联系。

1. 和频信号强度正比于和频光电场的平方。

2. 和频电场由和频极化——非线性光学过程中产生的电振荡偶极矩矢量——生成。联系二者的比例系数（$L$ 系数）依赖偏振方向。

3. 使用可见光和红外光时，和频极化由两束入射光的电场与表面宏观二阶非线性极化率张量的乘积表示。（表面以外，不具有反演对称的石英、GaAs、KDP晶体等物质也可能产生和频极化。）这种极化由介质电子性质引起的振动非共振背景，以及分子振动共振项组成；后者也可写为各分子产生的分子极化的矢量和。（背景项可能包含分子电子跃迁与可见光或和频光共振所增强的电子共振项。）

   严格地说，计算分子极化时，必须使用分子实际感受到的局域场，并考虑分子取向对极化大小的影响。

4. 通常把宏观二阶非线性极化率表示为分子响应的和，即取向平均。

5. 计算谱形时，若激光线宽远小于谱线宽度：(a) 对只采用一种入射偏振组合的实验，可将极化率表达式取模平方，因为可以认为该实验中的光电场始终相同；(b) 比较不同偏振组合测得的光谱时，表面电场强度随偏振改变，必须计入菲涅尔因子，以及连接极化与电场振幅的 $L$ 系数对偏振的依赖。因此，应比较所产生信号电场的模平方。

6. 激光线宽不可忽略时，应考虑电场强度随偏离激光中心频率的程度而改变：先按各频率求极化，再取该频率信号电场的模平方，最后在激光线宽内对频率积分。

> **译者说明：** 上述第6点先给出“平方后积分”的处理，后文第5部分及附录C会按相干性进一步区分，不能脱离后文把它当作一切脉冲的统一规则。这里的单分子 $\beta_v$ 对应二阶场响应，按项目命名属于一阶超极化率的相关系数，而不是线性分子极化率。

## 参数定义

在按展宽起因分别讨论计算方法之前，先定义下列量。

| 符号 | 原文定义 |
|---|---|
| $\omega_{\mathrm{IR}}$ | 红外光频率 |
| $\omega_v$ | 完全没有展宽时分子的吸收频率 |
| $\gamma_v$ | 均匀展宽的线宽（半高半宽） |
| $\Delta_{1/2}$ | 非均匀展宽的线宽（半高半宽） |
| $\beta_v$ | 单分子和频一阶超极化率中的矩阵元系数，即振动偶极矩与拉曼张量之积再乘以量纲换算常数；严格地说，它是按可见光、红外光电场方向及和频极化方向的组合指定的张量系数。因此，除原文所说的“(ss)偏振”情形外，须特别注意。 |
| $N$ | 产生和频信号的分子总数 |
| $\chi^{\mathrm{SFG}}$ | 宏观的表面和频二阶非线性极化率，严格地说也是张量 |

> **局部记号说明：** 本段改用小写 $\gamma_v$ 表示均匀宽度，前面要点使用大写 $\Gamma_v$；保留各自记号。后文也用“波数”称呼 $\omega$，不自行补入 $2\pi c$ 换算。原文“(ss)”只写两个偏振标签，未补出第三个。
