# 2.4 薄膜产生的和频（表达式）

> 原作：广瀬千秋
> 中文翻译：章力

## 准备工作

原点取在光线入射点处。若入射点有展宽，则取其中心。

z 轴：从媒质1指向媒质2的法线方向。

x 轴：取光线在界面上的行进方向（与波矢在界面上的投影方向一致）。

定义如下术语：

- 1/m 界面：媒质1与薄膜的界面。
- m/2 界面：薄膜与媒质2的界面。
- n1, n2, nm：媒质1、媒质2、薄膜 m 的折射率。
- k1, k2, km：媒质1、媒质2、薄膜 m 中的波矢。
- \theta1, \theta2, \thetam：媒质1、媒质2、薄膜 m 中光线行进方向与法线的夹角。
- t1m：从媒质1侧透射到薄膜侧的电场透射系数。
- tm1：从薄膜侧透射到媒质1侧的电场透射系数。
- r1m：从媒质1侧入射并在 1/m 界面反射的电场反射系数。
- rm1：从薄膜侧入射并在 m/1 界面反射的电场反射系数。
- tm2：从薄膜侧透射到媒质2侧的电场透射系数。
- t2m：从媒质2侧透射到薄膜侧的电场透射系数。
- rm2：从薄膜侧入射并在 m/2 界面反射的电场反射系数。
- r2m：从媒质2侧入射并在 m/2 界面反射的电场反射系数。
- 向上(-)光：从 m/2 界面朝向 m/1 界面的光，与反射光相同，沿 -z 方向行进。
- 向下(+)光：从 m/1 界面朝向 m/2 界面的光，与入射光相同，沿 +z 方向行进。

### 反射系数

$$
r12s = E_sr / E_si = (k1z - k2z)/(k1z + k2z) = (n1 cos\theta1 - n2 cos\theta2)/(n1 cos\theta1 + n2 cos\theta2)
     = -sin(\theta1 - \theta2)/sin(\theta1 + \theta2)

r12p = E_pr / E_pi = (\varepsilon1 k2z - \varepsilon2 k1z)/(\varepsilon2 k1z + \varepsilon1 k2z) = (n1 cos\theta2 - n2 cos\theta1)/(n2 cos\theta1 + n1 cos\theta2)
     = -tan(\theta1 - \theta2)/tan(\theta1 + \theta2)
$$

### 透射系数

$$
t12s = E_st / E_si = 2k1z/(k1z + k2z) = 2n1 cos\theta1/(n1 cos\theta1 + n2 cos\theta2)
     = 2cos\theta1 sin\theta2/sin(\theta1 + \theta2)

t12p = E_pt / E_pi = 2\varepsilon1 k2z cos\theta1/(\varepsilon2 k1z + \varepsilon1 k2z) = 2n1 cos\theta1/(n2 cos\theta1 + n1 cos\theta2)
     = 2cos\theta1 sin\theta2/sin(\theta1 + \theta2)cos(\theta1 - \theta2)

r21s = -r12s , r21p = -r12p

t21s = (n2 cos\theta2 / n1 cos\theta1) t12s , t21p = (n2 cos\theta2 / n1 cos\theta1) t12p
$$

以界面的内向法线为 z 轴、s 偏振的电场方向为 y 轴、光的正向行进方向为 x 轴，可求得电场各轴方向分量的系数如下。

$$
Ex,i = E_pi cos\theta1,  Ey,i = E_si,  Ez,i = -E_pi sin\theta1

Ex,r = E_pr cos\theta1,  Ey,r = E_sr,  Ez,r = E_pr sin\theta1

Ex,t = E_pt cos\theta2,  Ey,t = E_st,  Ez,t = -E_pt sin\theta2
$$

由上述关系，可得以下振幅反射系数和振幅等效系数。

$$
r12x = r12p,   r12y = r12s,  r12z = -r12p

r21x = -r12p,  r21y = -r12s,  r21z = r12p

t12x = (cos\theta2/cos\theta1) t12p,  t12y = t12s,  t12z = (sin\theta2/sin\theta1) t12p = (n1/n2) t12p

t21x = (n2/n1) t12p,  t12y = t12s,  t12z = (cos\theta2/cos\theta1) (n2/n1)^2 t12p

r1m,x = -rm1,x = r1m,p,  r1m,y = -rm1,y = r1m,s,  r1m,z = -rm1,z = -r1m,p

r2m,x = -rm2,x = r2m,p,  r2m,y = -rm2,y = r2m,s,  r2m,z = -rm2,z = -r2m,p

t1m,x = (cos\thetam/cos\theta1) t1m,p,  t1m,y = t1m,s,  t1m,z = (sin\thetam/sin\theta1) t1m,p

tm1,x = (cos\theta1/cos\thetam) tm1,p,  tm1,y = tm1,s,  tm1,z = (sin\theta1/sin\thetam) tm1,p

t2m,x = (cos\thetam/cos\theta2) t2m,p,  t2m,y = t2m,s,  t2m,z = (sin\thetam/sin\theta2) t2m,p

tm2,x = (cos\theta2/cos\thetam) tm2,p,  tm2,y = tm2,s,  tm2,z = (sin\theta2/sin\thetam) tm2,p

t1m,\alpha tm1,\alpha = 1 + r1m,\alpha rm1,\alpha = 1 - r1m,\alpha^2,  t2m,\alpha tm2,\alpha = 1 + r2m,\alpha rm2,\alpha = 1 - r2m,\alpha^2,  (\alpha = x, y, z)
$$

上述公式满足如下关系式。

1 + r12x = t12x,  1 + r12y = t12y,  1 + r12z = (n2/n1)^2 t12z （电场边界条件）

$$
1 + r12s r21s = 1 - (r12s)^2 = t12s t21s,  1 + r12p r21p = 1 - (r12p)^2 = t12p t21p
$$

顺便指出，由于光的强度正比于 E^2 n cos\theta，由 r12^2 n1 cos\theta1 + t12^2 n2 cos\theta2 = n1 cos\theta1 可知光的强度守恒。

## L系数与电场振幅

$$
E_SF, \alpha = \sum_\beta L_\alpha\beta P_\beta^SF
$$

此处省略了公共因子 $4\pi i \omega_{SF}/c$（当使用波数矢量代替折射率时，则为 $4\pi i \omega_{SF}^2/c^2$）。

L 系数的记号规则：Li/j, s(p), $\alpha$ 表示当极化片 m' 夹在 i 层与 j 层之间时，由极化强度的 $\alpha$ 分量（$\alpha = x, y, z$）产生的光的 s 偏振分量或 p 偏振分量之间的系数（注意：并非 x、y、z 分量）。向上(-)光与向下(+)光分别以上标 -、+ 区分。

对于媒质1与多层薄膜 m 之间的极化片 m' 产生的光：

$$
L^-_1/m,p,x = cos\thetam,SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)

L^-_1/m,s,y = 1 / (n1,SF cos\theta1,SF + nm,SF cos\thetam,SF)

L^-_1/m,p,z = (nm,SF / nm',SF) sin\thetam',SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)
           = (nm,SF / nm',SF)^2 sin\thetam,SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)

L^+_1/m,p,x = cos\theta1,SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)

L^+_1/m,s,y = 1 / (n1,SF cos\theta1,SF + nm,SF cos\thetam,SF)

L^+_1/m,p,z = -(n1,SF / nm',SF) sin\thetam',SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)
           = -(n1,SF / nm',SF)^2 sin\theta1,SF / (n1,SF cos\thetam,SF + nm,SF cos\theta1,SF)
$$

对于媒质2与多层薄膜 m 之间的极化片 m'' 产生的光：

$$
L^-_2/m,p,x = cos\theta2,SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)

L^-_2/m,s,y = 1 / (n2,SF cos\theta2,SF + nm,SF cos\thetam,SF)

L^-_2/m,p,z = (n2,SF / nm'',SF) sin\thetam'',SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)
           = (n2,SF / nm'',SF)^2 sin\theta2,SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)

L^+_2/m,p,x = cos\thetam,SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)

L^+_2/m,s,y = 1 / (n2,SF cos\theta2,SF + nm,SF cos\thetam,SF)

L^+_2/m,p,z = -(nm,SF / nm'',SF) sin\thetam'',SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)
           = -(nm,SF / nm'',SF)^2 sin\thetam,SF / (n2,SF cos\thetam,SF + nm,SF cos\theta2,SF)
$$

对于多层薄膜内部的极化片产生的光：

$$
L^-_m/m,p,x = L^+_m/m,p,x = cos\thetam,SF / (2 nm,SF cos\thetam,SF)

L^-_m/m,s,y = L^+_m/m,s,y = 1 / (2 nm,SF cos\thetam,SF)

L^-_m/m,p,z = -L^+_m/m,p,z = sin\thetam,SF / (2 nm,SF cos\thetam,SF)
$$

由此，各部位产生的 SFG 光电场振幅可表示为：

**来自 P(0) 的贡献**：（P(0^-) 是媒质1侧电场引起的极化强度，P(0^+) 是薄膜侧电场引起的极化强度）

$$
E^-_1,p(z = 0^-) = L^-_1/m,p,x P_x(0^-) + L^-_1/m,p,z P_z(0^-)

E^-_1,s(z = 0^-) = L^-_1/m,s,y P_y(0^-)

E^+_m,p(z = 0^+) = L^+_1/m,p,x P_x(0^+) + L^+_1/m,p,z P_z(0^+)

E^+_m,s(z = 0^+) = L^+_1/m,s,y P_y(0^+)

**来自 P(hm) 的贡献**：（P(hm^+) 是媒质2侧电场引起的极化强度，P(hm^-) 是薄膜侧电场引起的极化强度）

E^-_m,p(z = hm^-) = L^-_2/m,p,x P_x(hm^-) + L^-_2/m,p,z P_z(hm^-)

E^-_m,s(z = hm^-) = L^-_2/m,s,y P_y(hm^-)

E^+_2,p(z = hm^+) = L^+_2/m,p,x P_x(hm^+) + L^+_2/m,p,z P_z(hm^+)

E^+_2,s(z = hm^+) = L^+_2/m,s,y P_y(hm^+)

**来自 P(z) 的贡献**：

E^-_m,p(z) = L^-_m/m,p,x P_x(z) + L^-_m/m,p,z P_z(z)

E^-_m,s(z) = L^-_m/m,s,y P_y(z)

E^+_m,p(z) = L^+_m/m,p,x P_x(z) + L^+_m/m,p,z P_z(z)

E^+_m,s(z) = L^+_m/m,s,y P_y(z)
$$

## 1/m 界面的外侧 (x = -2nh_m tan\thetam,SF, z = 0^-) 的 SFG

### 反射 SFG

$$
E^-_1p(0-) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta\gamma
    (1 + r1m,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [(1 + r1m,vis,\beta rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma rm2,ir,\gamma e^{2i\betam,ir hm})]
  * [(1 + rm2,SF,p e^{2i\betam,SF hm}) L^-_1/m,px \chi_x\beta\gamma + (1 - rm2,SF,p e^{2i\betam,SF hm}) L^-_1/m,pz \chi_z\beta\gamma]
  / [1 + r1m,SF,p rm2,SF,p e^{2i\betam,SF hm}]
  ... (1a)

E^-_1s(0-) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta\gamma
    (1 + r1m,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [(1 + r1m,vis,\beta rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma rm2,ir,\gamma e^{2i\betam,ir hm})]
  * [(1 + rm2,SF,s e^{2i\betam,SF hm}) / (1 + r1m,SF,s rm2,SF,s e^{2i\betam,SF hm})] L^-_1/m,sy \chi_y\beta\gamma
  ... (1b)
$$

### 透射 SFG

$$
E^+_2p(hm+) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    (1 + r1m,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [(1 + r1m,vis,\beta rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma rm2,ir,\gamma e^{2i\betam,ir hm})]
  * [t1m,SF,p tm2,SF,p e^{i\betam,SF hm} / (1 + r1m,SF,p rm2,SF,p e^{2i\betam,SF hm})] [\chi_x\beta\gamma L^+_m/1,px + \chi_z\beta\gamma L^+_m/1,pz]
  ... (2a)

E^+_2s(hm+) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    (1 + r1m,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [(1 + r1m,vis,\beta rm2,vis,\beta e^{2i\betam,vis hm}) (1 + r1m,ir,\gamma rm2,ir,\gamma e^{2i\betam,ir hm})]
  * [t1m,SF,s tm2,SF,s e^{i\betam,SF hm} / (1 + r1m,SF,s rm2,SF,s e^{2i\betam,SF hm})] \chi_y\beta\gamma L^+_m/1,sy
  ... (2b)
$$

## 表面已形成薄膜时（折射率 m' 的分子膜）的 SFG

当表面已形成完整薄膜时，由构成该薄膜（折射率 m'）的分子产生的 SFG 需要考虑内部反射。

### 反射 SFG

$$
E^-_1p(0-) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    t1m',vis,\beta (1 + rm'm,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm})
  / [1 + r1m',vis,\beta rm'm,vis,\beta + (rm'm,vis,\beta + r1m',vis,\beta) rm2,vis,\beta e^{2i\betam,vis hm}]
  * t1m',ir,\gamma (1 + rm'm,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [1 + r1m',ir,\gamma rm'm,ir,\gamma + (rm'm,ir,\gamma + r1m',ir,\gamma) rm2,ir,\gamma e^{2i\betam,ir hm}]
  * (1 + r1m',SF,p rm'm,SF,p) [(1 + rm2,SF,p e^{2i\betam,SF hm}) \chi_x\beta\gamma L^-_1/m,px + (1 - rm2,SF,p e^{2i\betam,SF hm}) \chi_z\beta\gamma L^-_1/m,pz]
  / [1 + r1m',SF,p rm'm,SF,p + rm2,SF,p (r1m',SF,p + rm'm,SF,p) e^{2i\betam,SF hm}]
  ... (3a)

E^-_1s(0-) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    t1m',vis,\beta (1 + rm'm,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm})
  / [1 + r1m',vis,\beta rm'm,vis,\beta + (rm'm,vis,\beta + r1m',vis,\beta) rm2,vis,\beta e^{2i\betam,vis hm}]
  * t1m',ir,\gamma (1 + rm'm,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [1 + r1m',ir,\gamma rm'm,ir,\gamma + (rm'm,ir,\gamma + r1m',ir,\gamma) rm2,ir,\gamma e^{2i\betam,ir hm}]
  * (1 + r1m',SF,s rm'm,SF,s)(1 + rm2,SF,s e^{2i\betam,SF hm})
  / [1 + r1m',SF,s rm'm,SF,s + rm2,SF,s (r1m',SF,s + rm'm,SF,s) e^{2i\betam,SF hm}] \chi_y\beta\gamma L^-_1/m,sy
  ... (3b)
$$

### 透射 SFG

$$
E^+_2p(hm+) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    t1m',vis,\beta (1 + rm'm,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm})
  / [1 + r1m',vis,\beta rm'm,vis,\beta + (rm'm,vis,\beta + r1m',vis,\beta) rm2,vis,\beta e^{2i\betam,vis hm}]
  * t1m',ir,\gamma (1 + rm'm,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [1 + r1m',ir,\gamma rm'm,ir,\gamma + (rm'm,ir,\gamma + r1m',ir,\gamma) rm2,ir,\gamma e^{2i\betam,ir hm}]
  * tm2,SF,p (1 + r1m',SF,p rm'm,SF,p) e^{i\betam,SF hm}
  / [1 + r1m',SF,p rm'm,SF,p + rm2,SF,p (rmm',SF,p + rm'1,SF,p) e^{2i\betam,SF hm}] (L^+_1/m,px \chi_x\beta\gamma + L^+_1/m,pz \chi_z\beta\gamma)
  ... (4a)

E^+_2s(hm+) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    t1m',vis,\beta (1 + rm'm,vis,\beta)(1 + rm2,vis,\beta e^{2i\betam,vis hm})
  / [1 + r1m',vis,\beta rm'm,vis,\beta + (rm'm,vis,\beta + r1m',vis,\beta) rm2,vis,\beta e^{2i\betam,vis hm}]
  * t1m',ir,\gamma (1 + rm'm,ir,\gamma)(1 + rm2,ir,\gamma e^{2i\betam,ir hm})
  / [1 + r1m',ir,\gamma rm'm,ir,\gamma + (rm'm,ir,\gamma + r1m',ir,\gamma) rm2,ir,\gamma e^{2i\betam,ir hm}]
  * tm2,SF,s (1 + r1m',SF,s rm'm,SF,s) e^{i\betam,SF hm}
  / [1 + r1m',SF,s rm'm,SF,s + rm2,SF,s (rmm',SF,s + rm'1,SF,s) e^{2i\betam,SF hm}] L^+_1/m,sy \chi_y\beta\gamma
  ... (4b)
$$

## m/2 界面的外侧 (x = -(2n + 1)h_m tan\thetam,SF, z = hm^+) 的 SFG

### 反射 SFG

$$
E^-_1p(0-) = E^0_vis,\beta E^0_ir,\gamma \sum_\beta,\gamma
    t1m,vis,\beta tm2,vis,\beta t1m,ir,\gamma tm2,ir,\gamma e^{i(\betam,ir + \betam,vis) hm}
  / [(1 + r1m,vis,\beta rm2,vis,\beta e^{2i\betam,vis hm})(1 + r1m,ir,\gamma rm2,ir,\gamma e^{2i\betam,ir hm})]
  * [tm1,p e^{i\betam,SF hm} / (1 + r1m,p rm2,p e^{2i\betam,SF hm})] [L^-_2/m,px \chi_x\beta\gamma + L^-_2/m,pz \chi_z\beta\gamma]
  ... (7a)
