## 1. 序言

双甲基化合物是含CH伸缩振动的SFG张量分析中最为重要的官能团之一。在界面化学中，表面活性剂、自组装单分子膜(SAM)、脂质双层膜等众多体系中都含有双甲基基团。CH3基团本身具有C3v对称性，而(CH3)2X分子整体则因两个甲基的耦合使得对称性降低为C2v对称性。SFG张量的形式取决于分子的取向分布，双甲基基团的内部旋转自由度使得问题变得更为复杂。本章将详细推导(CH3)2X型分子在不同取向条件下的SFG张量表达式。

## 2. 坐标系与欧拉角

(1) 分子固有坐标系：(abc)系。C3轴为c轴，C原子和H原子构成的平面为ac面，三个CH键之一在ac面内。

(2) (CH3)2X分子中的两个甲基坐标系：(xyz)系。双甲基的C3轴为z轴，X原子位于yz面内。两个甲基共用一个C3轴，但绕z轴旋转使x轴为二等分线方向。

(3) 甲基取向角：z轴与C3轴一致，倾斜角a（即CXC角的一半）。每个甲基中AB两个CH键的取向由扭转角fA和fB描述。甲基的三个H原子相对于三角形底面的位相，当间隙取向（staggered）时，扭转角fA = 0, fB = 0。相对于三角形底面旋转180度即为重叠取向（eclipsed）。扭转角的组合决定了"伸缩振动"模式与"弯曲振动"模式对SFG张量的贡献。甲基中伸缩振动与弯曲振动的耦合比取决于扭转角，由于弯曲振动模式的张量分量符号关系不同，后续各类情况的分析将有所不同。

(4) 欧拉角(c, q, f)：将双甲基分子从分子坐标系变换到空间坐标系。CXC角为2a，两个甲基的欧拉角分别为(0, a, f)和(pi, a, f)（对应于以X原子为基准的底部取向）。

以下各情况的张量表达中，变量q以sin(q), sin(2q), sin(3q)等三角函数形式出现，利用倍角公式可以相互转换。主要的倍角公式为：

```
sin(2q) = 2 sin(q) cos(q)
cos(2q) = cos^2(q) - sin^2(q) = 2 cos^2(q) - 1 = 1 - 2 sin^2(q)
sin(3q) = 3 sin(q) - 4 sin^3(q)
sin(q) + sin(3q) = 4(sin(q) - sin^3(q))
cos(3q) = 4 cos^3(q) - 3 cos(q)
cos(q) - cos(3q) = 4(cos(q) - cos^3(q))
```

本节之后，将对典型取向分布情况下的(xyz)系张量依次进行推导。(CH3)2X由于含有两个甲基，取向角存在多个自由度，情况较复杂。

## 3. 振动模式

CH3的四个振动模式中，伸缩振动和弯曲振动对(CH3)2X型基团的SFG信号具有决定性的影响。以下将详细介绍各类振动模式的张量表达式。

### (1) 伸缩振动

两个CH3基团各自具有三个CH伸缩振动模式。对称伸缩振动（symmetric stretch）引起沿z轴的偶极变化，反对称伸缩振动（asymmetric stretch）引起沿x轴的偶极变化。此外，CXC骨架的弯曲振动也需要考虑。当CXC角为0或pi时，骨架振动的影响需要特别处理。当a = 0或pi/2时，x方向为全对称伸缩振动与反对称伸缩振动的叠加。

### (2) 弯曲振动

单个CH3的弯曲振动具有二重简并性。在(CH3)2X类型中，弯曲振动共计具有四重简并性。CH3的弯曲振动在(abc)坐标系中，a分量属于对称弯曲，b分量属于反对称弯曲。两个CH3基团的弯曲振动相互耦合，a分量在分子整体中为全对称，而弯曲振动在z方向为全对称，反对称弯曲振动在x方向产生分量。两个甲基的耦合使得振动模式进一步分裂。当a = 0或pi/2时，y方向分量为零。此时CXC角决定了两种弯曲振动模式中哪一方对反对称振动做出贡献。

进一步地，a分量贡献于伸缩振动，而弯曲振动在q方向（y方向）和反对称弯曲振动在CXC角各自由度方向均有贡献。(CH3)2X具有C2v对称性，对称振动属于a1对称性，反对称振动在面外z方向属于b1对称性（面内弯曲a2对称性），各振动张量按三个坐标分量展开后得到具体的张量表达式（详见各张量分量）。

当a = 0或pi/2时，可以观察到a分量的弯曲振动被淬灭，取而代之的是对称振动与弯曲振动的耦合贡献。

---

关于两个甲基的耦合：在后续分析中将看到，虽然两个C3轴共享同一个轴（单轴重叠配置），但在a = 0或pi/2的极限情况下，两者退化为单一甲基的对称性。CXC骨架的C2v或D-infinity-h对称性决定了耦合的方式，这些特征将在双甲基耦合的具体分子中体现。

## 4. (CH3)2X的对称性

CXC骨架的弯曲角决定了分子整体的对称性。根据两个甲基的扭转角组合，对称性可分为以下几种情况：

- **C2v**（fA = fB = 0 或 p）：全对称
- **C2v**（fA = fB != 0, p）：保持C2v对称性
- **C2**（绕z轴）：fA = 0, fB = p 或 fA = p, fB = 0
- **Cs**（xz面）：fA = -fB != 0
- **Cs**（yz面）：fA != +/-fB
- **C1**（一般情况）：不属于以上任何对称性（包含C3vA和C3vB类型的混合）

（此处的分类参考了Bunker等人的分子对称群处理方法。）

## 5. 分子坐标系中的SFG张量 —— 三种情况

根据扭转角fA和fB的不同组合，SFG张量分为不同情况讨论。

### 伸缩振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_aac ~ (4/9) b_zzz, b_ccc ~ (1/9) b_zzz。

#### 情况 fA = fB = 0, p（全对称，等价于2个重叠——2个eclipsed）

当fA = fB = 0时：cos(fA) = cos(fB) = cos(2fA) = cos(2fB) = cos(3fA) = cos(3fB) = +1

当fA = fB = p时：cos(fA) = cos(fB) = cos(3fA) = cos(3fB) = -1, cos(2fA) = cos(2fB) = +1

**(a1) 对称性：**

```
b_xxz = -2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_aac cos a
b_yyz = +2 b_aac cos a
b_zzz = +2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_ccc cos a
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

**(b1) 对称性：**

```
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

### 弯曲振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

注意：zyy和yzy属于b类弯曲振动，与a类弯曲振动符号相反。

#### 情况 fA = fB = 0（或 fA = fB = p）

**(a1) 对称性：**

```
b_xxz = -2 b_caa (cos a - cos 3a)
b_yyz = 0
b_zzz = 2 b_caa (cos a - cos 3a)
```

**(b1) 对称性：**

```
b_zxx = -b_caa (cos a - 2cos 3a)
b_xzx = -b_caa (cos a - 2cos 3a)
```

**(b2) 对称性：**

```
b_zyy = b_caa cos a
b_yzy = b_caa cos a
```

#### 情况 fA = fB != 0, p（2个eclipsed，取向一致）

此时 sin(n*fB) = -sin(n*fA), cos(n*fB) = cos(n*fA)。

**伸缩振动模式（a1和b1）：** 与上述fA = fB = 0, p情况下的表达式相同。

**弯曲振动模式：**

第三组分量（b类弯曲，a类弯曲符号相反）中，需注意a类弯曲振动与b类弯曲振动的区别。其中，需注意a类弯曲振动与b类弯曲振动具有不同的符号关系。

```
b_zxx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_xzx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_zyy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]
b_yzy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]
b_xxz = -2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_yyz = -b_aaa sin a (cos 3fA - cos fA)
b_zzz = 2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa sin 3a (cos 3fA - cos fA)
```

```
b_yzx = -(1/2) b_caa cos 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_zyx = -(1/2) b_caa cos 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_zxy = -(1/2) b_caa (2cos 2a - 1) sin 2fA - b_aaa sin a cos a [sin 3fA - (1/2) sin fA]
b_xzy = -(1/2) b_caa (2cos 2a - 1) sin 2fA - b_aaa sin a cos a [sin 3fA - (1/2) sin fA]
b_xyz = b_caa sin 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_yxz = b_caa sin 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
```

#### 情况 fA = 0, fB = p（或 fA = p, fB = 0）（单边eclipsed，另一边staggered）

**伸缩振动模式：** 与前述情况相同。

**弯曲振动模式：**

注意：zyy和yzy属于b类弯曲振动，与a类弯曲振动符号相反。当fA = 0, fB = p时（或fA = p, fB = 0时）：

```
b_zxx = -2 b_caa (cos a - 2 cos 3a)
b_xzx = -2 b_caa (cos a - 2 cos 3a)
b_zyy = 2 b_caa cos a
b_yzy = 2 b_caa cos a
b_xxz = -4 b_caa (cos a - cos 3a)
b_yyz = 0
b_zzz = 4 b_caa (cos a - cos 3a)
```

#### 情况 fA = -fB != 0, p（2个eclipsed，取向相反）

**伸缩振动模式：** 与前述情况相同。

**弯曲振动模式：** 需注意a类弯曲振动与b类弯曲振动不同的符号关系：

```
b_zxx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_xzx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_zyy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]
b_yzy = b_caa cos a [1 - (1/2) cos 2fA] - b_aaa sin a [cos 3fA - (1/2) cos fA]
b_xxz = -2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_yyz = -b_aaa sin a (cos 3fA - cos fA)
b_zzz = 2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa sin 3a (cos 3fA - cos fA)
```

```
b_yxx = b_caa sin a cos a sin 2fA - b_aaa cos 2a (sin 3fA - sin fA)
b_xyx = b_caa sin a cos a sin 2fA - b_aaa cos 2a (sin 3fA - sin fA)
b_xxy = 2 b_caa sin a cos a sin 2fA - b_aaa cos 2a [sin 3fA - (1/2) sin fA]
b_yyy = b_aaa [sin 3fA - (1/2) sin fA]
b_zzy = -(1/2) * 2 b_caa sin a cos a sin 2fA - b_aaa sin 2a [sin 3fA - (1/2) sin fA]
b_yzz = -b_caa sin a cos a sin 2fA - b_aaa sin 2a (sin 3fA - sin fA)
b_zyz = -b_caa sin a cos a sin 2fA - b_aaa sin 2a (sin 3fA - sin fA)
```

## 6. 实验室坐标系(XYZ)中的SFG张量

分子坐标系(xyz)中的张量通过欧拉角(c, q, f)变换到实验室坐标系(XYZ)，最终得到实验上可观测的SFG张量。由于变换较为复杂，这里汇总了前面各情况（类型A）的完整表达式，并扩展到所有取向分布情况（类型B至类型F）。

一般地，利用欧拉角将(CH3)2X分子取向变换到实验室坐标系，各参数的定义如下：

### (1) 扭转角f

CXC角（即骨架角）决定了f的可能取值。c轴方向需要关注两个甲基之间的取向角，因此分子面内的ab面相对于X轴的方向决定了扭转角的取值。当Z轴与c轴一致时，X原子在y方向上使CXC角产生面内的偏转角（< 90度）。（x方向的矢量与X方向的矢量之间的夹角由面内取向决定。）

(a) 分子面沿z轴方向无倾斜时：f = 0 或 p；CXC面沿z轴方向倾斜时则为 f = pi/2 或 3pi/2。

(b) 双甲基中存在两个甲基，A甲基的扭转角为f，(CH3)2X中B甲基的扭转角为-f。

(c) (CH3)2X的两个甲基耦合使得取向分布产生对称性：扭转角f可取0~2pi中任意值。

### (2) 倾斜角qtilt（tilt角）

分子相对于z轴（CXC二等分线）的倾斜角通常称为tilt角。N原子沿z轴方向的倾斜由倾斜角描述。Z轴的倾斜角使用q = pi - qtilt表示。对于(CH3)2X的两个CH3基团，qtilt < pi/2。

### (3) 面内旋转角cip（in-plane）

c轴在XY面上的投影与Z轴方向的X方向的夹角为面内取向角。当Z轴与c轴一致时，X方向的面内取向产生面内偏转角。Z轴为对称轴时，欧拉角c = pi/2 + cip。

(a) 面内CXC二等分线的X方向倾斜角a，取决于具体的Y方向转角a。面内CXC二等分线方向与X方向的取向关系决定了cip = +a 或 -a的各种组合。

(b) 面内旋转角可自由取值，cip可取0~2pi内的任意值。

---

本节内容按分子对称性分类，包含了：取向无序情况、fA = fB = 0 或 p 情况、fA = fB != 0, p 情况、以及fA = 0, fB = p（或fA = p, fB = 0）情况，并对各类情况的张量分量进行了详细推导。

所有四种情况均有以下对称关系：
- 伸缩振动中：b_zxx = b_xzx
- 弯曲振动中：b_zxx = b_xzx, b_zyy = b_yzy
- （对于各情况）b_yzx = b_zyx, b_zxy = b_xzy, b_xyz = b_yxz

此外，取向无序的情况（类型B）与取向特定情况（类型C、D、E）之间存在相似性，本节对各情况的张量进行了全面的对比。在计算过程中，利用CXC面内扭转角f的对称性（当cos(nf)=0, sin(nf)=0时简化）可以进一步简化表达式。

本节将张量分为"CH3伸缩振动的SFG张量"和"CH2弯曲振动的SFG张量"两部分进行讨论。

---

## 类型A：(CH3)2X的SFG张量 —— 分子坐标系中各取向情况

### 分子坐标系定义

1. 分子固有坐标系：(a, b, c) 系。C3轴沿c方向，C原子和H原子构成的平面为ac面，三个CH键之一在ac面内。

2. (CH3)2X中双甲基的坐标系：(x, y, z) 系。双甲基的C3轴为z轴，X原子位于yz面内。两个甲基共享一个C3轴，x轴为二等分线方向。

3. 甲基取向角：z轴与C3轴一致，倾斜角为a（CXC角的一半）。每个甲基的A, B两个CH键的取向由扭转角fA, fB决定。甲基的三个H原子相对于三角形底面，当间隙取向时fA = 0, fB = 0。相对于三角形底面旋转180度为重叠取向。扭转角的组合决定了"伸缩振动"和"弯曲振动"对SFG张量的贡献。此时，弯曲振动与伸缩振动的耦合比是扭转角的函数，由于两种模式在取向对称性上有所不同，后续将分别讨论。

4. 欧拉角(c, q, f)：双甲基分子从分子坐标系到空间坐标系的变换。CXC角为2a，(0, a, f)和(pi, a, f)为两个甲基的欧拉角（脚底取向基准）。

张量变换的一般公式为：

```
b_ijk = sum_{a,b,c} U_{ijk:abc} * beta_{abc}  (i, j, k = x, y, z)
```

其中系数矩阵U_{ijk:abc}参考了Appl. Spectrosc.文献中的(xyz)系张量变换公式。自变量q以sin(q), sin(2q), sin(3q)等三角函数形式出现，利用前面的倍角公式可以相互转换。

### 伸缩振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_aac ~ (4/9) b_zzz, b_ccc ~ (1/9) b_zzz。

（注：此处为取向无序情况下的表达式。）

```
b_xxz = -2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_aac cos a
b_yyz = +2 b_aac cos a
b_zzz = +2(b_aac - b_ccc)(cos a - cos 3a) + 2 b_ccc cos a
b_zxx = -2(b_aac - b_ccc)(cos a - cos 3a)
b_xzx = -2(b_aac - b_ccc)(cos a - cos 3a)
```

### 弯曲振动模式

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

（注：第三组和第四组分量分别对应a类弯曲与b类弯曲的不同情况。需注意a类弯曲振动与b类弯曲振动的区别。）

**组1：**

```
b_zxx = -(1/2) b_caa (cos a - 2 cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_xzx = -(1/2) b_caa (cos a - 2 cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_zyy = (1/2) b_caa cos a [2 - (1/2)(cos 2fA + cos 2fB)]
       - (1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (1/2)(cos fA + cos fB)]
b_yzy = (1/2) b_caa cos a [2 - (1/2)(cos 2fA + cos 2fB)]
       - (1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (1/2)(cos fA + cos fB)]
b_xxz = -b_caa (cos a - cos 3a)[2 - (cos 2fA + cos 2fB)]
       + (1/2) b_aaa (sin a - sin 3a)[(cos 3fA + cos 3fB) - (cos fA + cos fB)]
b_yyz = -(1/2) b_aaa sin a [(cos 3fA + cos 3fB) - (cos fA + cos fB)]

c_ZZX = -2(b_aac - b_ccc)(cos a - cos 3a)[(sin q - sin 3q) cos c (1 + cos 2f) - sin q cos q sin c sin 2f]

c_ZXX = -(1/2)(b_aac - b_ccc)(cos a - cos 3a){2[cos q (1 + cos 2c cos 2f)
      - (cos q - cos 3q)(1 + cos 2c)(1 + cos 2f)] + (1 - 3 cos 2q) sin 2c sin 2f}

c_XZX = -(1/2)(b_aac - b_ccc)(cos a - cos 3a){2[cos q (1 + cos 2c cos 2f)
      - (cos q - cos 3q)(1 + cos 2c)(1 + cos 2f)] + (1 - 3 cos 2q) sin 2c sin 2f}

c_XXZ = -(b_aac - b_ccc)(cos a - cos 3a)[-(cos q - cos 3q)(1 + cos 2c)(1 + cos 2f) + sin 2q sin 2c sin 2f]
c_ZZZ = -2(b_aac - b_ccc)(cos a - cos 3a)(cos q - cos 3q)(1 + cos 2f)
```

**求和关系：**
```
c_XXX + c_YYX + c_ZZX = c_XXY + c_YYY + c_ZZY = c_XXZ + c_YYZ + c_ZZZ = 0
```

### 弯曲振动模式（类型C）

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

取向有序情况下（fA = fB = 0, p）的弯曲振动张量，第三和第四组分量通过取向平均展开：

```
b_xxz + b_yyz = -4 b_caa (cos a - cos 3a) - 2 b_aaa sin 3a
b_xxz - b_yyz = -4 b_caa (cos a - cos 3a) - 2 b_aaa (2 sin a + sin 3a)
b_xxz + b_yyz - 2 b_zzz = -12 b_caa (cos a - cos 3a) - (1/2)*2 b_aaa sin 3a
b_zxx = -2 b_caa (cos a - 2 cos 3a) - (1/2)*2 b_aaa (sin a - sin 3a)
b_zyy = 2 b_caa cos a - (1/2)*2 b_aaa sin a
```

### (a1) 对称性分量（弯曲振动，类型C）

详细的ppp和其他偏振组合表达式已在上方给出。具体形式与前述情况类似，包含sin(q), cos(q), sin(3q), cos(3q)以及sin(c), cos(c), sin(3c), cos(3c)的各项，加上cos(2f)和sin(2f)的贡献。

### (b1) 对称性分量（弯曲振动，类型C）

采用简化的(b1)表达式，其中：

```
b_caa = b_zzz (cos a - cos 3a) ~ 2*sqrt(3)/9 b_zzz (Td), 3/8 b_zzz (sp2)
```

### (b2) 对称性分量（弯曲振动，类型C）

类似地，b2分量的表达式采用cos(a)的依赖关系。

### 弯曲振动模式（类型D）

条件：b_zzz >> b_xxz, b_hhz，且 b_caa ~ (4/9) b_zzz, b_aaa ~ (4*sqrt(2)/9) b_zzz。

类型D情况下，弯曲振动具有非平凡的fA依赖性：

```
b_xxz + b_yyz = -2 b_caa (cos a - cos 3a)(1 - cos 2fA) - b_aaa sin 3a (cos 3fA - cos fA)
b_xxz - b_yyz = -2 b_caa (cos a - cos 3a)(1 - cos 2fA) + b_aaa (2 sin a - sin 3a)(cos 3fA - cos fA)
b_xxz + b_yyz - 2 b_zzz = -6 b_caa (cos a - cos 3a)(1 - cos 2fA) - 3 b_aaa sin 3a (cos 3fA - cos fA)
b_zxx = -b_caa (cos a - 2 cos 3a)(1 - cos 2fA) + b_aaa (sin a - sin 3a)(cos 3fA - cos fA)
b_zyy = b_caa cos a (1 - (1/2) cos 2fA) - b_aaa sin a (cos 3fA - (1/2) cos fA)
b_xyz = b_yxz = b_caa sin 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_yzx = b_zyx = -(1/2) b_caa sin 2a sin 2fA - b_aaa sin a cos a (sin 3fA - sin fA)
b_zxy = b_xzy = -(1/2) b_caa (2 cos 2a - 1) sin 2fA - b_aaa sin a cos a (sin 3fA - (1/2) sin fA)
```

### (a1) 对称性分量（弯曲振动，类型D）

**ppp偏振组合（部分）：**

c_XZX = (3/4)[2 b_caa (cos a - cos 3a)(1 - cos 2fA) - b_aaa sin 3a (cos 3fA - cos fA)](cos q - cos 3q)

## 结论

本章系统推导了(CH3)2X型双甲基分子在SFG光谱中的张量表达式。通过考虑两个甲基的不同扭转角组合(fA, fB)，将对称性区分为C2v、C2、Cs、C1等多种情况。对于每种情况，分别给出了伸缩振动模式和弯曲振动模式在分子坐标系(xyz)和实验室坐标系(XYZ)中的完整SFG张量。

主要结论如下：
1. 伸缩振动模式主要由a1对称性的zzz分量主导，zzz >> xxz, hhz。
2. 弯曲振动模式的贡献取决于两个甲基的相对扭转角，在fA = fB = 0, p时最为简单。
3. (a1)和(b1)对称性分量满足求和定则：c_XXX + c_YYX + c_ZZX = 0等。
4. 一般情况（类型F）包含最完整的表达式，涵盖了任意扭转角组合的情况。
