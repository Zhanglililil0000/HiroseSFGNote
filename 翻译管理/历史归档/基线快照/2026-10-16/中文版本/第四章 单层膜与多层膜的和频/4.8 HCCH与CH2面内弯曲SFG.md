## 1. 序言

金刚石表面的CH伸缩振动是研究界面结构的重要探针。单晶金刚石表面通过化学修饰可形成各种CH终端结构，这些结构在SFG光谱中表现出特征性的信号。本章以金刚石C(100)表面为模型体系，系统分析HCCH和CH2基团的SFG张量。

金刚石as-cut表面中，C原子的悬挂键（dangling bond）有两个或一个。两个悬挂键被氢封端后形成二氢化物(dihydride)结构（见图a），而monohydride结构则是单氢封端（见图b）。as-cut表面上两个悬挂键形成的褶皱结构实际上可由上下交错排列的dihydride结构表示。

在这些结构中，CH振动的耦合形成两类特征振动基团（mode group）：一类为HCCH基团（模式组a），另一类为CH2基团（模式组b）。这两类基团的振动耦合方式差异很大，其SFG张量也因此具有不同的特征，需分别进行解析。

本章对HCCH和CH2两类基团的振动模式进行SFG张量的理论分析。

金刚石晶格常数约为3.567 Angstrom，C-C键长约1.545 Angstrom。其中表面区域C原子的高约2.51 Angstrom（对于as-cut表面）。表面褶皱的尺寸约为2.51 x 5.1 Angstrom（参见R. E. Stallcup et al., Appl. Phys. Lett. 66, 2331 (1995)）。表面原子层C-C键的键幅约为2.0 Angstrom，原子层下方的键幅约为3.1 Angstrom。C-H键长约为1.1~1.2 Angstrom。

对于CH2的褶皱(b)面来说，其面外方向具有较大的位阻，因此CH2的H原子键幅约为0.7 Angstrom。而对于HCCH模式组(a)的面外方向，其空间更为宽敞，H原子键幅约为2 Angstrom（CH键与表面夹角约30度而向外倾斜，与表面法线约55度的角度进一步增大位阻）。

此外，表面原子之间的间距较大。在面内方向的H原子间距为约1.20 Angstrom（范德华半径）。表面原子的键角约为2.4 Angstrom，因此面内方向的位阻相对较小。褶皱(b)面在面内方向的位阻与面外方向基本相同。另一方面，褶皱(a)面中，由于HCCH模式组的H原子间距足够大，面内方向的位阻相对宽松。但需要注意的是，面内方向的位阻通常小于面外方向，因此CH的面内弯曲振动贡献相对较小。

面内方向的位阻较大时，通常H原子保持面外方向，而面外取向的原子间距离增大，因此面内取向的H原子键幅被限制在较小值，面外H原子取向的键幅则相对较大。

CH2基团整体具有C2对称性，两个H原子分别处于对称和反对称位置，面内方向的弯曲振动是允许的。但HCCH基团中，面内方向的弯曲对应的CH变形模式中，HCC角的变化方式以及面内方向的旋转（摆动模式）和面外方向的扭转（扭转模式）的耦合情况更为复杂。

此外，面内方向的位阻使得这些模式组的CH振动容易产生混合。不同的模式组之间会因面内方向的位阻而产生混合，且基团间的距离越近混合越强。HCCH模式组的特点在于，其C2v和C2两种对称性的混合情况不同。

在C2v对称性下，H原子之间的距离为等价距离，对称和反对称两种振动具有不同的特征频率，面内方向的位阻使面内弯曲振动的频率发生分裂，从而产生两种不同的振动模式。而在C2对称性下，等价距离被打破，振动模式的混合导致两个CH之间产生交换，HCCH整体呈现出复杂的振动耦合特征。

CH2模式组中，3原子构成的结构产生对称和反对称两种不同的振动。其中2个H原子的对称性决定了整体为C2v对称性。

### 3. 分子取向：欧拉角(c, q, f)

分子(abc)系通过欧拉角(c, q, f)变换到(xyz)系。角度型欧拉角(c, q, f)的定义与前文一致。

---

#### (1) 扭转角f

ac面（对于CH2而言是CHH面，对于HCCH而言是HCH面）绕c轴的取向由f决定。c轴方向需要关注ac面的取向，因此根据a与z轴以及ab面内X方向的关系确定扭转角。（a方向矢量的x分量与x方向矢量的夹角由面内取向决定。）

ac面沿c轴方向无倾斜时：f = 0 或 p；ac面沿c轴方向倾斜时则为 f = pi/2 或 3pi/2。

分子取向的对称性决定了扭转角f可取0~2pi中任意值。

#### (2) 倾斜角qtilt（tilt角）

分子相对于c轴的倾斜角称为tilt角。c轴在(-z)方向上的倾斜由tilt角描述。N原子（沿c方向）相对于z轴的倾斜由倾斜角决定，在ab面（xy面）方向上相对于c轴的倾斜由面内倾斜角描述。z轴方向的倾斜角使用q = pi - qtilt表示。

#### (3) 面内旋转角cip（in-plane）

c轴相对于z轴的倾斜方向，在xy面上投影与x轴的夹角为面内取向角。当z轴与c轴一致时，x方向的面内取向产生面内偏转角。z轴为对称轴时，欧拉角c = pi/2 + cip。

分子取向的面内旋转可自由取值，cip可取0~2pi内任意值。

## 3. 分子(abc)系中的张量分量

按照前文的分析方法，本节给出(abc)系张量分量的基本结果。这些结果将用于后续各取向情况下的SFG张量推导。

### C2v对称性（CH2及对称HCCH）

C2v分子的非零张量分量为：
- b_aac, b_bbc, b_ccc
- b_caa = b_aca
- b_cbb = b_bcb

### C2对称性（反对称HCCH）

C2分子的非零张量分量为：
- b_aac, b_bbc, b_ccc
- b_abc = b_bac
- b_caa = b_aca
- b_bca = b_cba
- b_cbb = b_bcb
- b_cab = b_acb

### CH伸缩振动的张量分量

以上对于分子(abc)系的基本结果中，CH伸缩振动的张量分量通过"欧拉角"和"分子取向分布"两个因素进一步展开。对于CH2，使用"欧拉角" Eu-5进行展开：

(1) 两个CH键的夹角c取值为2a（HCH角），因此sinc, sin3c, cosc, cos3c各项中包含键角的贡献。当c = 0或pi时，sin2c = 0, cos2c = +1，因此sin2c和(1-cos2c)项均消除。

(2) 面内角f取零值时，sinf = sin2f = sin3f = 0, cosf = cos2f = cos3f = +1，因此sinf, sin2f, sin3f, (1-cos2f)项均消除。

综合以上两个因素，利用"分子取向分布"将两个CH键的贡献叠加后得到如下结果：

### CH2基团的张量分量（Td键角）

```
b_aac = 2 {b_xxz cos^3(a/2) + b_zzz [cos(a/2) - cos^3(a/2)]}                                    (3-1a)
b_bbc = 2 b_hhz cos(a/2)                                                                        (3-1b)
b_ccc = 2 {b_xxz [cos(a/2) - cos^3(a/2)] + b_zzz cos^3(a/2)}                                    (3-1c)
b_caa = b_aca = -2(b_xxz - b_zzz)[cos(a/2) - cos^3(a/2)]                                        (3-2)
b_cbb = b_bcb = 0                                                                                (3-3)
```

（CH伸缩振动的b张量分量中，反对称分量的贡献在此处已被忽略。）

以HCH角为四面体角为例：cos a = -1/3, sin a = 2*sqrt(2)/3, cos(a/2) = sqrt(1/3)。代入得：

```
b_aac = (2*sqrt(3)/9)(b_xxz + 2 b_zzz)                                                         (3-4a)
b_bbc = (2*sqrt(3)/9)(3 b_hhz)                                                                  (3-4b)
b_ccc = (2*sqrt(3)/9)(2 b_xxz + b_zzz)                                                          (3-4c)
b_caa = b_aca = -(4*sqrt(3)/9)(b_xxz - b_zzz)                                                   (3-5)
```

注意CH伸缩振动中b_aac ~ b_ccc，两者的量级相当。

### HCCH基团（对称情况）的张量分量

对于HCCH（对称情况），分析方法类似，但使用"欧拉角" Eu-6代替Eu-5，其中(a/2)被替换为a - pi/2（其中a为HCC角），结果如下：

```
b_aac = 2 [b_xxz sin^3 a + b_zzz (sin a - sin^3 a)]                                            (3-6a)
b_bbc = 2 b_hhz sin a                                                                           (3-6b)
b_ccc = 2 [b_xxz (sin a - sin^3 a) + b_zzz sin^3 a]                                            (3-6c)
b_caa = b_aca = -2(b_xxz - b_zzz)(sin a - sin^3 a)                                             (3-7)
```

以HCC角为四面体角为例：cos a = -1/3, sin a = 2*sqrt(2)/3。代入得：

```
b_aac = (4*sqrt(2)/37)(8 b_xxz + b_zzz)                                                         (3-8a)
b_bbc = (4*sqrt(2)/37)(9 b_hhz)                                                                 (3-8b)
b_ccc = (4*sqrt(2)/37)(b_xxz + 8 b_zzz)                                                         (3-8c)
b_caa = b_aca = -(4*sqrt(2)/37)(b_xxz - b_zzz)                                                  (3-9)
```

注意此时b_aac < b_ccc，且b_caa的值显著较小。

### HCCH基团（反对称情况）的张量分量

对于HCCH（反对称情况），使用"欧拉角" Eu-8, Eu-10等，欧拉角中HCC角和CH键二等分角均需要独立处理，且键角的两个参数需要分别指定。利用"分子取向分布"对欧拉角进行展开后得到：

```
b_aac = (b_xxz + b_hhz) cos q
    - (1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q)(1 + cos 2c)
    - (1/2)(b_xxz - b_hhz){[cos q (1 - cos 2c) - cos 3q (1 + cos 2c)] cos 2f + 2 cos 2q sin 2c sin 2f}
                                                                                                 (3-10a)

b_bbc = (b_xxz + b_hhz) cos q
    - (1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q)(1 - cos 2c)
    - (1/2)(b_xxz - b_hhz){[cos q (1 + cos 2c) - cos 3q (1 - cos 2c)] cos 2f - 2 cos 2q sin 2c sin 2f}
                                                                                                 (3-10b)

b_ccc = (b_xxz + b_hhz) cos q
    - (b_xxz + b_hhz - 2 b_zzz) cos 3q
    + (b_xxz - b_hhz)(cos q - cos 3q) cos 2f
                                                                                                 (3-10c)

b_abc = b_bac = (1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q) sin 2c
    - (1/2)(b_xxz - b_hhz)[(cos q + cos 3q) sin 2c cos 2f + 2 cos 2q cos 2c sin 2f]
                                                                                                 (3-10d)

b_caa = b_aca = -(1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q)(1 + cos 2c)
    - (1/2)(b_xxz - b_hhz)[(cos q - cos 3q)(1 + cos 2c) cos 2f - sin 2q sin 2c sin 2f]
                                                                                                 (3-11a)

b_bca = b_cba = (1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q) sin 2c
    + (1/2)(b_xxz - b_hhz)[(cos q - cos 3q) sin 2c cos 2f + sin 2q (1 + cos 2c) sin 2f]
                                                                                                 (3-11b)

b_cbb = b_bcb = -(1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q)(1 - cos 2c)
    - (1/2)(b_xxz - b_hhz)[(cos q - cos 3q)(1 - cos 2c) cos 2f + sin 2q sin 2c sin 2f]
                                                                                                 (3-12a)

b_cab = b_acb = (1/2)(b_xxz + b_hhz - 2 b_zzz)(cos q - cos 3q) sin 2c
    + (1/2)(b_xxz - b_hhz)[(cos q - cos 3q) sin 2c cos 2f - sin 2q (1 - cos 2c) sin 2f]
                                                                                                 (3-12b)
```

### 含键角a和扭转角t的一般情况

当键角a和扭转角t均需明确指定时（对应于反对称HCCH的一般取向情况），使用更一般的公式（Eu-8~Eu-10扩展），结果如下：

```
b_aac = 2 (b_xxz sin^2 a + b_zzz cos^2 a) sin a cos(t/2)                                       (3-13a)

b_bbc = 2 [b_xxz cos^2 a sin^2(t/2) + b_hhz cos^2(t/2) + b_zzz sin^2 a sin^2(t/2)] sin a cos(t/2)
                                                                                                 (3-13b)

b_ccc = 2 [b_xxz cos^2 a cos^2(t/2) + b_hhz sin^2(t/2) + b_zzz sin^2 a cos^2(t/2)] sin a cos(t/2)
                                                                                                 (3-13c)

b_abc = b_bac = 2(b_xxz - b_zzz)[sin a cos a sin(t/2)] sin a cos(t/2)                           (3-13d)

b_caa = b_aca = -2(b_xxz - b_zzz) sin a cos^2 a cos(t/2)                                       (3-14a)

b_bca = b_cba = -2 [b_xxz cos^2 a - b_hhz + b_zzz sin^2 a] cos a sin(t/2) cos(t/2)             (3-14b)

b_cbb = b_bcb = +2 [b_xxz cos^2 a - b_hhz + b_zzz sin^2 a] sin a sin^2(t/2) cos(t/2)          (3-15a)

b_cab = b_acb = -2(b_xxz - b_zzz) sin 2a cos a cos(t/2)                                        (3-15b)
```

以HCC角为四面体角（cos a = -1/3, sin a = 2*sqrt(2)/3）代入得：

```
b_aac = (4*sqrt(2)/27)(8 b_xxz + b_zzz) cos(t/2)                                               (3-16a)

b_bbc = (4*sqrt(2)/27)[(b_xxz - 9 b_hhz + 8 b_zzz) sin^2(t/2) + 9 b_hhz] cos(t/2)             (3-16b)

b_ccc = (4*sqrt(2)/27)[(b_xxz - 9 b_hhz + 8 b_zzz) cos^2(t/2) + 9 b_hhz] cos(t/2)             (3-16c)

b_abc = b_bac = -(4*sqrt(2)/27)(b_xxz - b_zzz)(2*sqrt(2)) sin(t/2) cos(t/2)                   (3-16d)

b_caa = b_aca = -(4*sqrt(2)/27)(b_xxz - b_zzz) cos(t/2)                                        (3-17a)

b_bca = b_cba = +(2/27)[b_xxz - 9 b_hhz + 8 b_zzz] sin(t/2) cos(t/2)                           (3-17b)

b_cbb = b_bcb = +(4*sqrt(2)/27)[b_xxz - 9 b_hhz + 8 b_zzz] sin^2(t/2) cos(t/2)                (3-18a)

b_cab = b_acb = +(8/27)(b_xxz - b_zzz) cos(t/2)                                                (3-18b)
```

## 4. 表面(xyz)系中的HCCH张量分量

对于典型取向分布情况，表面坐标系中的张量分量可以通过上述(abc)系分量和适当的坐标变换得到。其中取向无序的情况（类型A）已在前面给出一般表达式，以下针对特殊取向情况（立式和卧式）给出简化结果。扭转角t为面内（ac面）相对于面外（xy面）的旋转角。

### 4a. 立式HCCH（垂直站立）

分子沿[ac面]沿表面法线方向站立，倾斜角t使得HCCH呈垂直姿态，双方向沿表面法线取向。使用"欧拉角" Eu-4（双方向取向）进行变换。

键角a为CCH角。

旋转操作：Rz(c = -pi/2) Ry(q = -t) Rz(f = pi/2)，以及 Rz(c = -pi/2) Ry(q = +t) Rz(f = pi/2)。

代入条件 t = pi/2 - q：

```
sin c = -1,  sin 2c = 0,  sin 3c = +1,  cos c = 0,  cos 2c = -1,  cos 3c = 0
sin f = +1,  sin 2f = 0,  sin 3f = -1,  cos f = 0,  cos 2f = -1,  cos 3f = 0
sin q = -sin t,  cos q = cos t
```

（注意HCCH的两个取向分别为-t和+t。）

得到立式HCCH的SFG张量如下：

#### 对角(diagonal)伸缩振动模式

**(ppp):**

```
c_xxz = b_aac cos t
c_zzz = -(b_bbc - b_ccc) cos 3t + b_bbc cos t
```

**(spp):**

```
c_yzz = -(b_bbc - b_ccc)(sin t - sin 3t)
```

**(ssp):**

```
c_yyz = (b_bbc - b_ccc) cos 3t + b_ccc cos t
```

**(psp):**

```
c_zyz = -(b_bbc - b_ccc)(sin t - sin 3t)
```

**(sps):**

```
c_yzy = -(b_bbc - b_ccc)(cos t - cos 3t)
```

**(pps):**

```
c_xxy = -b_aac sin t
c_zzy = -b_bbc sin 3t - b_ccc (sin t - sin 3t)
```

**(pss):**

```
c_zyy = -(b_bbc - b_ccc)(cos t - cos 3t)
```

**(sss):**

```
c_yyy = -b_bbc (sin t - sin 3t) - b_ccc sin 3t
```

#### 非对角(off-diagonal)伸缩振动模式

**(ppp):**

```
c_zxx = b_caa cos t
c_xzx = b_caa cos t
```

**(spp):**

```
c_yxx = -b_caa sin t
```

**(psp):**

```
c_xyx = -b_caa sin t
```

**(ssp), (sps), (pps), (pss), (sss):** 无（none）

#### 用CH伸缩振动张量代入（Td键角情况）

将(3-6)式和Td键角下的(3-8)式代入，得到具体的表达式：

**对角伸缩振动模式：**

```
c_xxz = (4*sqrt(2)/27)(8 b_xxz + b_zzz) cos t
c_zzz = (4*sqrt(2)/27)(b_xxz - 9 b_hhz + 8 b_zzz) cos 3t

c_yzz = -(4*sqrt(2)/27)(b_xxz - 9 b_hhz + 8 b_zzz)(sin t - sin 3t)

c_yyz = (4*sqrt(2)/27)[-(b_xxz - 9 b_hhz + 8 b_zzz)(cos t - cos 3t) + 9 b_hhz cos t]

c_zyz = -(4*sqrt(2)/27)(b_xxz - 9 b_hhz + 8 b_zzz)(sin t - sin 3t)

c_yzy = (4*sqrt(2)/27)(b_xxz - 9 b_hhz + 8 b_zzz)(cos t - cos 3t)

c_xxy = -(4*sqrt(2)/27)(9 b_hhz) sin t
c_zzy = -(4*sqrt(2)/27)[(b_xxz - 9 b_hhz + 8 b_zzz)(sin t - sin 3t) - 9 b_hhz sin t]

c_zyy = (4*sqrt(2)/27)(b_xxz - 9 b_hhz + 8 b_zzz)(cos t - cos 3t)

c_yyy = -(4*sqrt(2)/27)[(b_xxz - 9 b_hhz + 8 b_zzz) sin 3t + 9 b_hhz sin t]
```

**非对角伸缩振动模式：**

```
c_zxx = -(4*sqrt(2)/27)(b_xxz - b_zzz) cos t
c_xzx = -(4*sqrt(2)/27)(b_xxz - b_zzz) cos t

c_yxx = (4*sqrt(2)/27)(b_xxz - b_zzz) sin t
```

## 结论

本章系统分析了金刚石C(100)表面上HCCH和CH2两类CH振动基团的SFG张量。通过考虑不同的表面取向情况（立式、卧式、垂直、倾斜、面内/面外取向等），给出了完整的分量表达式。

主要结论：

1. **HCCH基团**：立式HCCH产生以ppp偏振为主的强信号，卧式HCCH则表现出更多的非对角分量。
2. **CH2基团**：垂直CH2以(1+cos2c)和(1-cos2c)形式依赖于面内旋转角，倾斜和面内取向则产生更复杂的张量结构。
3. **C2v与C2对称性**：C2v对称性下无b_abc等交叉项，C2对称性下这些交叉项对SFG信号产生显著贡献。
4. **实验室坐标系**：通过欧拉角(c,q,f)变换后，(XYZ)系中的表达式包含了全部偏振组合(ppp, spp, ssp, psp, sps, pps, pss, sss)。
5. **1-cos2f因子**：在倾斜+面内取向的CH2中，1-cos2f项在q和t的特定组合下为零，使得某些信号消失，这是实验上判断取向的重要依据。
