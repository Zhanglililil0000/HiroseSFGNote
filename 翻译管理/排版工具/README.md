# Markdown 数学参考渲染

用途：按批次将译文中的 Markdown 与 LaTeX 数学生成本地 HTML 和检查图，不调用远程渲染服务，不修改正文。

固定依赖：marked 15.0.12、KaTeX 0.16.22（含配套 CSS、woff2 字体），取自 jsDelivr 对应版本的 npm 分发。浏览器使用本机 Edge/Chromium，无界面运行。脚本当前按批检查 1.1 的已处理部分，后续可按批次扩展，不在每次执行时渲染整本。

运行：使用 Node 执行本目录“检查译文.cjs”，传入 --b002 检查前两批，--b003 仅检查第三批，--b004 仅检查第四批，--b005 仅检查第五批，--b006 仅检查第六批，--b007 仅检查第七批，--b008 检查第八批工作稿，--b009 检查第九批工作稿。项目工作目录须为 HiroseSFGNote 的父目录。检查结果写入翻译管理/历史归档/逐节校订/1.1，各批指标合并保存；未改动的前批不必重复渲染。

本地 HTML 引用本机样式与字体，仅作项目内预览，不是可移植发布包。参考环境通过不等于任意 Markdown 软件通过；输出图仍需视觉检查，不能只看解析成功。

`--b010`检查式（12）完整转录；结果和截图保存在1.1校订记录目录。

`--b011`检查式（13）定义及前两组的部分工作稿，不代表整式完成。

`--b012`检查式（13）第3、4主组的部分工作稿。

`--b013`检查式（13）整式及未决读法注释；排版通过不代表疑点解决。
