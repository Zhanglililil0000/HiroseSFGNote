# 日常维护

1. 以“中文版本”的独立小节为稿源，维护章节清单、就地注释及勘误附件。
2. 从项目根目录运行本目录的[重建合稿.py](重建合稿.py)，传入`--batch Bxxx`；加`--browse`可同时检查全部阅读页面。该入口依次完成清单、Markdown、HTML、数学语法及锚点核验，浏览快照进入“全书复核/验收快照”。
3. 使用[生成阅读包.py](生成阅读包.py)，传入同一`--batch Bxxx`生成“交付版本/当前阅读版”及带版本号ZIP。生成器会拒绝未登记残留文件，也会核对批号。
4. 使用[验收阅读包.cjs](验收阅读包.cjs)检查独立交付目录。结构与迁移追溯由[检查结构.py](检查结构.py)检查，B678迁移程序已单独归档。

这些工具依赖本机Python、Node及浏览器；浏览工具当前使用配置中的Edge路径。已打包阅读版无需这些运行环境。根目录历史脚本已归档，不能从旧批次一键重放修订；一次性目录迁移程序也已归档。
